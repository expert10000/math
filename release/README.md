# Theory of Mathematics I–VIII Release Evidence

This directory is generated from canonical repository evidence.

- `SERIES_RELEASE_DASHBOARD.md` — human release-readiness matrix.
- `SERIES_MASTER_MANIFEST.tsv` — per-volume chapter/build/PDF/source baseline.
- `SERIES_MASTER_MANIFEST.sha256` — hashes of primary series-control evidence.
- `SERIES_RELEASE_READINESS.json` — machine-readable readiness and unresolved items.

A volume is not called released merely because a PDF exists. Release readiness
requires the status ledger, successful canonical build, and PDF/source evidence
to agree.
