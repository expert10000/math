# Shared LaTeX Infrastructure

This directory will hold common publication infrastructure extracted from the legacy standalone documents.

Planned canonical files:

- `preamble.tex`
- `macros.tex`
- `theorem_styles.tex`
- `notation.tex`
- `bibliography.bib`
- `figures/`

These files are intentionally **not** created as empty placeholders. They should be introduced only after duplicate preambles/macros have been compared and a canonical definition has been chosen.
