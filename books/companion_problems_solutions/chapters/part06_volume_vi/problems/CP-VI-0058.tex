\subsection*{CP-VI-0058: Irreducibility and coordinate rings}

Let $X$ be an affine algebraic set. Prove that $X$ is irreducible if and only if $I(X)$ is prime, equivalently if and only if $k[X]$ is an integral domain.

\medskip
\noindent\textbf{Solution.}

If $X$ is reducible, write $X=V(I)\cup V(J)=V(IJ)$ with both pieces proper. Choose $f\in I\setminus I(X)$ and $g\in J\setminus I(X)$. Then $fg\in I(X)$ while neither factor lies in $I(X)$, so $I(X)$ is not prime. Conversely, if $fg\in I(X)$ but neither factor lies in $I(X)$, then $X=V(f)\cup V(g)$ and both closed subsets are proper, so $X$ is reducible. The quotient $k[X]=k[x_1,\dots,x_n]/I(X)$ is a domain exactly when $I(X)$ is prime.
