\subsection*{CP-VI-0098: Trivial line bundle and global generators}

Show that an invertible sheaf $\mathcal L$ on $X$ is trivial if and only if it has a global section $s$ whose germ generates the rank-one free module $\mathcal L_x$ for every $x\in X$.

\medskip
\noindent\textbf{Solution.}

If $\mathcal L\cong\mathcal O_X$, the image of $1$ is such a section. Conversely, a section $s$ defines a morphism $\mathcal O_X\to\mathcal L$, $1\mapsto s$. On each stalk this sends $1$ to a basis element, hence is an isomorphism. A morphism of sheaves that is an isomorphism on all stalks is an isomorphism, so $\mathcal L\cong\mathcal O_X$.
