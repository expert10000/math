\subsection*{CP-VI-0069: Sections of the structure sheaf on a basic open}

Let $X=\operatorname{Spec}A$ and $f\in A$. Prove the fundamental affine formula
\[
\Gamma(D(f),\mathcal O_X)\cong A_f.
\]
Explain the case $f=1$.

\medskip
\noindent\textbf{Solution.}

Put $B=A_f$. The basic opens $D(fg)$ inside $D(f)$ correspond to
$D(g)$ in $\operatorname{Spec}B$, and the locally defined fraction sections
are represented by elements of $B_g$. We verify explicitly the gluing
statement that makes these local fractions into exactly the elements of $B$.

Suppose $D(g_1),\ldots,D(g_r)$ cover $\operatorname{Spec}B$ and that
$s_i\in B_{g_i}$ agree on every overlap $D(g_ig_j)$. The cover condition is
equivalent to $(g_1,\ldots,g_r)=B$. After increasing exponents, write
\[
s_i=\frac{b_i}{g_i^n}\quad(b_i\in B)
\]
with one common $n$. Equality on overlaps means that for some common
$M\geq0$,
\[
(g_ig_j)^M(g_j^n b_i-g_i^n b_j)=0
\qquad\text{for all }i,j.
\]
Choose $N=n+M$ and set $d_i=g_i^{N-n}b_i\in B$. Then
\[
g_j^N d_i=g_i^N d_j\quad\text{for all }i,j.
\]
Since the $g_i$ generate the unit ideal, so do their $N$th powers.
Choose $c_i\in B$ with $\sum_i c_i g_i^N=1$, and define
\[
b=\sum_i c_i d_i\in B.
\]
For each $j$ we have
\[
g_j^N b=\sum_i c_i g_j^N d_i
=\sum_i c_i g_i^N d_j=d_j.
\]
Thus $b=s_j$ in $B_{g_j}$. This proves existence of a global element.
If $b\in B$ restricts to zero in every $B_{g_i}$, some common $K$ satisfies
$g_i^K b=0$ for all $i$. Because the $g_i^K$ generate $B$, we get $b=0$;
hence the global element is unique.

The affine structure sheaf is built by gluing these compatible local
fractions on distinguished opens. The established equalizer calculation
shows that every section over $D(f)$ comes from a unique element of
$B=A_f$. Consequently
\[
\boxed{\Gamma(D(f),\mathcal O_X)\cong A_f.}
\]
For $f=1$, we have $D(1)=X$ and $A_1=A$, so
$\Gamma(X,\mathcal O_X)\cong A$.
