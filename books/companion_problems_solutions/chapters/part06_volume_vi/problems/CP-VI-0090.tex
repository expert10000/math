\subsection*{CP-VI-0090: No global affine coordinates on projective space}

Compute $\Gamma(\mathbb P_k^n,\mathcal O)$ for $n\ge1$ and show that every global regular function is constant.

\medskip
\noindent\textbf{Solution.}

A global regular function restricts on each standard chart to a polynomial in affine coordinates, and on overlaps these polynomials must agree under the projective transition maps. Equivalently, using the Proj description for the standard graded polynomial ring, global degree-zero regular functions are elements of degree zero compatible on all localizations. The only such homogeneous rational functions without poles are constants. Hence $\Gamma(\mathbb P_k^n,\mathcal O)=k$.
