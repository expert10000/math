\chapter*{Problem and Reference Convention}
\addcontentsline{toc}{chapter}{Problem and Reference Convention}

Stable identifiers use the form
\[
  \texttt{CP-I-0001},\quad \texttt{CP-VI-0021},\quad \texttt{CP-VIII-0004},
\]
where the Roman numeral indicates the main Volume to which the problem is most closely
related, and the final field is a four-digit, zero-padded identifier. The identifier does not assert final placement in that Volume.

Reader-facing correspondence is textual, for example:
\begin{quote}
\textbf{Related material.} Volume VI, Chapters VI/18--VI/20.
\end{quote}

The machine-readable atlas may record more precise section-level relationships, source
semantic units, solution availability, and visual requirements.
