   640: \[
   641: \sum_{n=0}^N a_n x^n
   642: = (1-x)\sum_{n=0}^N S_n x^n + S_N x^{N+1}.
   643: \tag{A}
   644: \]
   645: 
   646: \paragraph{Dirichlet test (series).}
   647: If $(S_n)$ is bounded and $(b_n)$ is monotone with $b_n\to 0$, then $\sum a_n b_n$ converges.
   648: 
   649: \paragraph{Uniform Dirichlet on intervals.}
   650: If $\sup_n |S_n|\le M$ and for each $x$ in a set $E$ the sequence $b_n(x)$ is monotone in $n$ with
   651: $\sup_{x\in E} |b_n(x)|\to 0$, then $\sum a_n b_n(x)$ converges uniformly on $E$.
   652: In particular, for fixed $r\in(0,1)$, the series $\sum a_n x^n$ converges uniformly on $[0,r]$ and on $[r,1)$.
   653: 
   654: \paragraph{Abelâ€™s theorem (boundary continuity for power series).}
   655: If $\sum_{n=0}^\infty a_n$ converges (so $S_n\to S$) and $f(x)=\sum_{n=0}^\infty a_n x^n$ for $x\in[0,1)$,
   656: then $f$ extends continuously to $x=1$ with
   657: \[
   658: \lim_{x\to 1^-} f(x)=\sum_{n=0}^\infty a_n.
   659: \]
   660: \emph{Proof sketch via (A):} write $f(x)=(1-x)\sum_{n\ge0} S_n x^n$ and compare with the geometric kernel
   661: $\sum_{n\ge0} x^n=(1-x)^{-1}$; boundedness of $(S_n)$ yields the limit $S$.
   662: 
   663: \paragraph{Differentiation inside $\sum a_n x^n$ on $(-1,1)$.}
   664: If $\sum a_n$ converges then for each $r\in(0,1)$:
   665: \[
   666: \sum_{n=0}^\infty a_n x^n \text{ and } \sum_{n=1}^\infty n a_n x^{n-1}
   667: \quad\text{converge uniformly on } [-r,r],
   668: \]
   669: hence $f(x)=\sum a_n x^n$ is $C^1$ on $(-1,1)$ with $f'(x)=\sum n a_n x^{n-1}$.
   670: \emph{Reason:} apply (A) to control tails by bounded $S_n$ and the factors $(1-x)$, together with Dirichletâ€™s test
   671: for $\sum S_n [(n+1)x^n-nx^{n-1}]$ on compact subintervals of $(-1,1)$.
   672: 
   673: \paragraph{Quick checklist.}
   674: \begin{itemize}
   675: 	\item Use (A) to pass $x\to 1^-$ or to prove uniform convergence on $[r,1]$.
   676: 	\item If $(S_n)$ bounded and $x^n$ monotone $\downarrow 0$, then $\sum a_n x^n$ converges (Dirichlet).
   677: 	\item For termwise differentiation, restrict to $|x|\le r<1$ and use uniform Dirichlet.
   678: 	\item Need convergence of $\sum n|a_n|$ only if you want uniform convergence of $f'$ on all of $(-1,1)$.
   679: \end{itemize}

  4555: \subsection*{How simple functions and regular functions are related}
  4556: 
  4557: The Minkowski inequality (and many foundational results in integration
  4558: theory) is first proved for \emph{simple functions}, because these have
  4559: a completely transparent structure:
  4560: \begin{itemize}
  4561: 	\item simple functions are finite linear combinations of indicator sets;
  4562: 	\item all integrals reduce to finite sums;
  4563: 	\item Tonelli--Fubini can be verified directly;
  4564: 	\item no pathological behaviour can occur.
  4565: \end{itemize}
  4566: Once the inequality is established for simple functions, one extends it
  4567: to general measurable functions (continuous, $C^\infty$, polynomials,
  4568: Gaussians, trigonometric functions, etc.) by:
  4569: \begin{itemize}
  4570: 	\item approximation from below by increasing sequences of simple functions;
  4571: 	\item the Monotone or Dominated Convergence Theorem;
  4572: 	\item density of simple functions in $L^p$.
  4573: \end{itemize}
  4574: We now describe this relation step by step.
  4575: 
  4576: \subsubsection*{1. Simple functions as the foundational case}
  4577: 
  4578: A simple function has the form
  4579: \[
  4580: F(x,y) = \sum_{k=1}^m a_k\,1_{A_k}(x)\,1_{B_k}(y), \qquad a_k\ge 0.
  4581: \]
  4582: For such $F$, all integrals become finite sums:
  4583: \[
  4584: \int_{\mathbb{R}^n}\int_{\mathbb{R}^n} F(x,y)\,dy\,dx
  4585: = \sum_{k=1}^m a_k\,|A_k|\,|B_k|.
  4586: \]
  4587: Thus Minkowski's inequality for $p=1$ is an equality for simple functions.
  4588: 
  4589: \subsubsection*{2. Approximation of general nonnegative measurable functions}
  4590: 
  4591: Every nonnegative measurable function $F$ on $\mathbb{R}^n\times\mathbb{R}^n$
  4592: admits an increasing sequence of simple functions $F_n$ such that
  4593: \[
  4594: F_n(x,y) \uparrow F(x,y) \qquad\text{for all }(x,y).
  4595: \]
  4596: This construction is canonical and works for every $F\ge 0$.
  4597: 
  4598: \subsubsection*{3. The Monotone Convergence Theorem connects the two}
  4599: 
  4600: By the Monotone Convergence Theorem,
  4601: \[
  4602: \int F_n \to \int F,
  4603: \qquad
  4604: \int \Bigl|\int F_n(\cdot,y)\,dy\Bigr| \to 
  4605: \int \Bigl|\int F(\cdot,y)\,dy\Bigr|.
  4606: \]
  4607: Since Minkowski holds exactly for each $F_n$, taking limits shows it holds
  4608: for $F$ as well.

  3004: \section*{Problem 13$^{\ast}$}
  3005: Let $(X,d)$ be a non-empty complete metric space and let $f:X\to X$ be a function such that
  3006: for each positive integer $n$ we have
  3007: \begin{enumerate}[(i)]
  3008: 	\item if $d(x,y)<n+1$ then $d(f(x),f(y))<n$;
  3009: 	\item if $d(x,y)<1/n$ then $d(f(x),f(y))<1/(n+1)$.
  3010: \end{enumerate}
  3011: Must $f$ have a fixed point?
  3012: 
  3013: \bigskip
  3014: \hrule
  3015: \bigskip
  3016: 
  3017: \paragraph{Theory.}
  3018: (Boyd--Wong / Matkowski contraction.)
  3019: If there is a function $\phi:[0,\infty)\to[0,\infty)$ such that
  3020: $\phi(r)<r$ for all $r>0$ and
  3021: \[
  3022: d(fx,fy)\le \phi\big(d(x,y)\big)\qquad\forall\,x,y\in X,
  3023: \]
  3024: then $f$ has a unique fixed point on any complete metric space.
  3025: 
  3026: \bigskip
  3027: \paragraph{Solution.}
  3028: Define a piecewise function
  3029: \[
  3030: \phi(t)=
  3031: \begin{cases}
  3032: 	\lceil t\rceil - 1, & t\ge 1,\\[3pt]
  3033: 	\dfrac{1}{n+1}, & \text{if } \dfrac{1}{n+1}<t\le \dfrac{1}{n},\quad n\in\mathbb N.
  3034: \end{cases}
  3035: \]
  3036: Then $\phi(t)<t$ for all $t>0$.  
  3037: 
  3038: 
  3039: By (i) and (ii), we have $d(fx,fy)\le \phi(d(x,y))$.
  3040: 
  3041: 
  3042: Thus $f$ is a generalized contraction in the sense of Boyd--Wong, so
  3043: $f$ has a (necessarily unique) fixed point.
  3044: 
  3045: Uniqueness also follows since
  3046: $d(f(p),f(q))<d(p,q)$ is impossible if both $p,q$ are fixed.

   533: \section*{Understanding $d$-open sets and the subspace topology}
   534: 
   535: \subsection*{What ``$d$-open'' means}
   536: 
   537: Given a metric \(d\) on a set \(X\), we say a subset \(U\subseteq X\) is \emph{$d$-open}
   538: if for every point \(x\in U\) there exists a radius \(r>0\) such that the
   539: \emph{open $d$-ball}
   540: \[
   541: B_d(x,r)=\{\,y\in X:\ d(x,y)<r\,\}
   542: \]
   543: is contained in \(U\).
   544: 
   545: \smallskip
   546: 
   547: Equivalently, \(U\) is a union of $d$-balls.
   548: The collection of all $d$-open sets forms the \textbf{topology induced by $d$}.
   549: 
   550: \medskip
   551: 
   552: \subsection*{What the subspace topology is}
   553: 
   554: Suppose \(Y\) is a topological space (for example, a metric space with its metric--induced open sets),
   555: and \(X\subseteq Y\).
   556: 
   557: The \textbf{subspace topology} on \(X\) is defined as
   558: \[
   559: \mathcal{T}_X=\{\,U\cap X : U\subseteq Y \text{ is open in } Y\,\}.
   560: \]
   561: 
   562: \smallskip
   563: 
   564: So a set \(A\subseteq X\) is open in the subspace topology if and only if
   565: it is the intersection of \(X\) with some open subset of the ambient space \(Y\).
   566: 
   567: \medskip
   568: 
   569: \subsection*{How these relate (and to Problem 4)}
   570: 
   571: \begin{itemize}
   572: 	\item Start with \(Y=\mathbb{R}\) equipped with the usual metric \(|\cdot|\).
   573: 	\item Take \(X=(0,1]\subset Y\).
   574: 	\item The subspace topology on \(X\) consists of all sets of the form \((a,b)\cap(0,1]\).
   575: 	
   576: 	For example:
   577: 	\begin{itemize}
   578: 		\item The set \((0.2,0.7]\) is \emph{not} open in \(X\)
   579: 		because the point \(0.7\) would need a right-hand neighborhood inside \(X\),
   580: 		which does not exist.
   581: 		\item The set \((0.2,0.7)\) \emph{is} open in \(X\).
   582: 	\end{itemize}
   583: \end{itemize}
   584: 
   585: \smallskip
   586: 
   587: In Problem~4 we defined a new metric on \(X\) by
   588: \[
   589: d(x,y)=\left|\frac{1}{x}-\frac{1}{y}\right|.
   590: \]
   591: 
   592: The key property required was:
   593: \[
   594: \text{a subset of } X \text{ is open with respect to } d
   595: \quad\text{iff}\quad
   596: \text{it is open in the usual Euclidean subspace topology.}
   597: \]
   598: 
   599: \smallskip
   600: 
   601: That means:
   602: \[
   603: \text{$d$-open sets on $X$} \;=\; \text{open sets of the subspace topology from $\mathbb{R}$.}
   604: \]
   605: 
   606: So the metric \(d\) does not change which sets are open;
