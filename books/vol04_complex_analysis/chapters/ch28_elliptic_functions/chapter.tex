\chapter{Elliptic Functions}
\label{ch:iv28}

Elliptic functions are meromorphic functions periodic with respect to a rank-two lattice. Compactness of the associated torus forces strong balance laws for zeros, poles, and residues.

\section*{Learning goals}
After this chapter, the reader should be able to:
\begin{itemize}
\item verify double periodicity of candidate elliptic functions with respect to a lattice;
\item use compactness of the torus to prove global constraints on elliptic functions;
\item count zeros and poles of elliptic functions with multiplicity in a fundamental domain;
\item apply residue balance to elliptic functions on the torus;
\item construct elliptic functions from lattice-periodic meromorphic data;
\item distinguish singly periodic functions from genuinely doubly periodic elliptic functions;
\end{itemize}

An elliptic function satisfies $f(z+\omega)=f(z)$ for every lattice period $\omega\in\Lambda$.

\section{Descent to the torus}
Elliptic functions are exactly meromorphic functions on $\mathbb C/\Lambda$ pulled back to the plane.

\section{Poles in a period cell}
A nonconstant elliptic function must have poles because a holomorphic function on the compact torus would be constant.

\section{Zero-pole balance}

\section{Abel-type position constraint}

\section{Constructing elliptic functions}
Periodic principal parts must satisfy residue compatibility before a global elliptic function can exist.

\section{Even and odd examples}

\section{Function-field preview}
For a fixed lattice, elliptic functions are generated algebraically by $\wp$ and $\wp'$.

\section{Core structural results}

\begin{theorem}[Residue sum theorem]\label{thm:iv28-01}
The sum of residues of an elliptic function in a fundamental parallelogram containing no poles on its boundary is zero.
\begin{proof}
Integrate around the boundary. Opposite edges cancel because the function is periodic and the orientations are opposite. The residue theorem then forces the interior residue sum to vanish.
\end{proof}
\end{theorem}

\begin{theorem}[Equal zero and pole count]\label{thm:iv28-02}
A nonzero elliptic function has equally many zeros and poles in a fundamental parallelogram, counted with multiplicity.
\begin{proof}
Apply the argument principle to $f'/f$. This quotient is elliptic, so opposite-edge contour integrals cancel, leaving zero; hence zeros minus poles equals zero.
\end{proof}
\end{theorem}

\begin{theorem}[No single simple pole]\label{thm:iv28-03}
There is no elliptic function with exactly one simple pole modulo the lattice.
\begin{proof}
Such a function would have one nonzero residue in a fundamental parallelogram, contradicting the residue-sum theorem.
\end{proof}
\end{theorem}
