\chapter{Linear Transformations}
\label{ch:i05-linear-transformations}

Linear transformations are the morphisms of vector spaces: they preserve exactly the operations that define linear structure. Once linearity is recognized, a map is determined by its action on a basis, compositions remain linear, and apparently different formulas become instances of the same operator calculus.

\section*{Learning goals}
After this chapter, the reader should be able to:
\begin{itemize}
\item verify or refute linearity by testing additivity and homogeneity;
\item determine a linear transformation uniquely from its values on a basis;
\item construct a linear map satisfying prescribed images of basis vectors;
\item compute compositions of linear transformations and identify when two maps commute;
\item decide whether a proposed inverse map is linear and actually inverts the original transformation;
\item translate geometric actions such as projections, reflections, and coordinate permutations into linear maps;
\end{itemize}
\section*{Conceptual roadmap}
The chapter is organized around a repeated pattern:
\[
\boxed{\text{definition}\;\longrightarrow\;\text{structural theorem}\;\longrightarrow\;\text{coordinate calculation}\;\longrightarrow\;\text{application}.}
\]
Whenever possible, we separate the invariant mathematical object from a chosen coordinate representation.

\section{Definition and first consequences}
A map $T:V\to W$ is linear if $T(av+bw)=aT(v)+bT(w)$. Then $T(0)=0$ and all finite linear combinations pass through $T$.


% BEGIN VOL01-EXPANSION I05-example-01
\begin{example}[A fast linearity diagnosis]\label{ex:i05-expand-01}
Consider
\[
F(x,y)=(x+y,xy).
\]
Although the first coordinate is linear, the second is not. Indeed
\[
F(1,0)+F(0,1)=(1,0)+(1,0)=(2,0),
\]
while
\[
F(1,1)=(2,1).
\]
Thus additivity fails.

A useful diagnostic order is: first test \(F(0)=0\); then test additivity or
homogeneity on simple vectors. One failed identity settles nonlinearity, so
there is no reason to expand a general formula unnecessarily.
\end{example}
% END VOL01-EXPANSION I05-example-01
\section{Determination by a basis}
A linear map is uniquely determined by its values on a basis of the domain. Conversely, arbitrary images of basis vectors extend uniquely to a linear map.


% BEGIN VOL01-EXPANSION I05-example-02
\begin{example}[Constructing a map from basis data]\label{ex:i05-expand-02}
Let \(T:\mathbb R^2\to\mathbb R^3\) satisfy
\[
T(e_1)=(1,0,1),\qquad T(e_2)=(0,1,1).
\]
Since \((x,y)=xe_1+ye_2\), linearity forces
\[
T(x,y)=xT(e_1)+yT(e_2)=(x,y,x+y).
\]
Substituting \(e_1,e_2\) recovers the prescribed values, so the formula is
checked.

This is the basic construction principle: arbitrary images may be assigned to
basis vectors, and there is exactly one linear extension.
\end{example}
% END VOL01-EXPANSION I05-example-02
\section{Algebra of operators}
For fixed $V,W$, the set $\mathcal L(V,W)$ is a vector space under pointwise addition and scalar multiplication. Endomorphisms $\mathcal L(V)$ also compose.

\section{Composition}
The composite of linear maps is linear. Composition is associative and distributes over addition but is generally not commutative.


% BEGIN VOL01-EXPANSION I05-example-03
\begin{example}[Composition order matters]\label{ex:i05-expand-03}
Let \(P(x,y)=(x,0)\) and \(R(x,y)=(-y,x)\). Then
\[
(RP)(x,y)=R(x,0)=(0,x),
\]
whereas
\[
(PR)(x,y)=P(-y,x)=(-y,0).
\]
Thus \(RP\neq PR\).

Geometrically, projecting and then rotating is not the same as rotating and
then projecting. The calculation explains why operator multiplication is
noncommutative even though vector addition is commutative.
\end{example}
% END VOL01-EXPANSION I05-example-03
\section{Inverse maps}
A bijective linear map has a linear inverse. Such maps are isomorphisms and identify vector spaces as having the same linear structure.

\section{Important operators}
Differentiation on polynomials, evaluation functionals, coordinate projections, inclusion maps, shifts, and matrix multiplication are canonical examples.

\section{Core structural results}

\begin{theorem}[Extension from a basis]\label{thm:i05-01}
If $B=(v_1,\ldots,v_n)$ is a basis of $V$ and $w_i\in W$ are arbitrary, there is a unique linear $T:V\to W$ with $T(v_i)=w_i$.
\begin{proof}
Write each $v$ uniquely as $\sum a_i v_i$ and define $T(v)=\sum a_iw_i$. Uniqueness follows because any linear map must use this formula.
\end{proof}
\end{theorem}

\begin{theorem}[Inverse of an isomorphism]\label{thm:i05-02}
If $T:V\to W$ is linear and bijective, then $T^{-1}:W\to V$ is linear.
\begin{proof}
Write $y_j=T(x_j)$. Then $T^{-1}(ay_1+by_2)=T^{-1}(T(ax_1+bx_2))=ax_1+bx_2$.
\end{proof}
\end{theorem}

\section{Worked examples}

\begin{example}[Differentiation]\label{ex:i05-worked-01}
$D:\mathcal P_n\to\mathcal P_{n-1}$, $D(p)=p'$, is linear because differentiation respects sums and scalar multiples.
\end{example}

\begin{example}[Evaluation]\label{ex:i05-worked-02}
For fixed $a$, $E_a(p)=p(a)$ is a linear functional on a polynomial space.
\end{example}

\begin{example}[Shear]\label{ex:i05-worked-03}
$T(x,y)=(x+y,y)$ is linear and invertible, with inverse $(u,v)\mapsto(u-v,v)$.
\end{example}

\section{Diagnostic checklist}
Before moving on, it is useful to distinguish four levels of understanding:
\begin{enumerate}
\item recognize the definitions in unfamiliar examples;
\item prove the core structural statements without coordinates when possible;
\item translate the same statement into a matrix or coordinate computation;
\item know which hypotheses are essential and produce a counterexample when one is removed.
\end{enumerate}

\section{Solved dossiers}
These dossiers are longer worked problems. They complement the shorter exercise--hint--solution triads by combining several ideas in one argument.

\begin{problem}[Basis images determine a map]\label{prob:i05-dossier-01}
Let $T:\mathbb R^2\to\mathbb R^3$ satisfy $T(e_1)=(1,0,1)$ and $T(e_2)=(0,1,1)$. Compute $T(x,y)$.
\end{problem}
\begin{solution}
Linearity gives $T(x,y)=xT(e_1)+yT(e_2)=(x,y,x+y)$. No other linear map can have the prescribed basis images.
\end{solution}

\begin{problem}[Detecting nonlinearity quickly]\label{prob:i05-dossier-02}
Is $F(x,y)=(x+y,xy)$ linear?
\end{problem}
\begin{solution}
No. The second component is quadratic. For instance $F(2,0)=(2,0)$ while $2F(1,0)=(2,0)$ happens to agree, but $F(1,1)=(2,1)$ whereas $F(1,0)+F(0,1)=(2,0)$, so additivity fails.
\end{solution}

\begin{problem}[Differentiation as an operator]\label{prob:i05-dossier-03}
On $\mathcal P_3$, determine $\ker D$ and $\operatorname{im}D$ for $D(p)=p'$.
\end{problem}
\begin{solution}
The derivative is zero exactly for constant polynomials, so $\ker D=\mathcal P_0$. Every polynomial of degree at most $2$ has an antiderivative in $\mathcal P_3$, so $\operatorname{im}D=\mathcal P_2$.
\end{solution}

\begin{problem}[Composition order]\label{prob:i05-dossier-04}
Let $P(x,y)=(x,0)$ and $R(x,y)=(-y,x)$. Compare $RP$ and $PR$.
\end{problem}
\begin{solution}
$RP(x,y)=R(x,0)=(0,x)$, whereas $PR(x,y)=P(-y,x)=(-y,0)$. Thus composition is not commutative.
\end{solution}

\begin{problem}[A nilpotent map]\label{prob:i05-dossier-05}
Define $N(x,y,z)=(y,z,0)$. Determine the smallest $k$ with $N^k=0$.
\end{problem}
\begin{solution}
$N^2(x,y,z)=(z,0,0)$ and $N^3=0$, while $N^2\ne0$. Thus the nilpotency index is $3$.
\end{solution}

\begin{problem}[Evaluation functional]\label{prob:i05-dossier-06}
Show $E_1:\mathcal P_2\to\mathbb R$, $E_1(p)=p(1)$, is linear and find its values on $1,x,x^2$.
\end{problem}
\begin{solution}
Evaluation respects sums and scalar multiples. Each of $1,x,x^2$ takes value $1$ at $x=1$, so the functional is determined by the coordinate row $(1,1,1)$.
\end{solution}

\begin{problem}[Inverse linearity]\label{prob:i05-dossier-07}
If $T$ is a bijective linear map, prove $T^{-1}$ is linear.
\end{problem}
\begin{solution}
Write $y_i=T(x_i)$. Then $T^{-1}(ay_1+by_2)=T^{-1}(T(ax_1+bx_2))=ax_1+bx_2=aT^{-1}y_1+bT^{-1}y_2$.
\end{solution}

\begin{problem}[Zero map versus zero vector]\label{prob:i05-dossier-08}
Explain the difference between the zero vector in $W$ and the zero element of $\mathcal L(V,W)$.
\end{problem}
\begin{solution}
The zero vector is a single element $0_W$. The zero operator is a function $0:V\to W$ sending every $v$ to $0_W$. It is the additive identity in the vector space of linear maps.
\end{solution}

\begin{problem}[A projection decomposition]\label{prob:i05-dossier-09}
Let $P(x,y,z)=(x,y,0)$. Show $P^2=P$ and describe its fixed vectors and kernel.
\end{problem}
\begin{solution}
Applying $P$ twice changes nothing after the first application, so $P^2=P$. Fixed vectors satisfy $z=0$, the $xy$-plane; the kernel is the $z$-axis.
\end{solution}

\begin{problem}[A linear map from a formula]\label{prob:i05-dossier-10}
For $T(A)=A+A^T$ on $M_2(\mathbb R)$, prove linearity and characterize the image.
\end{problem}
\begin{solution}
Transpose is linear, so $T(\alpha A+\beta B)=\alpha T(A)+\beta T(B)$. Every output is symmetric. Conversely, if $S$ is symmetric then $T(S/2)=S$, so the image is exactly the symmetric matrices.
\end{solution}

\begin{problem}[Restriction to a subspace]\label{prob:i05-dossier-11}
Let $T(x,y,z)=(x+y,y+z,z)$. Is the plane $U=\{z=0\}$ invariant?
\end{problem}
\begin{solution}
If $(x,y,0)\in U$, then $T(x,y,0)=(x+y,y,0)\in U$. Hence the restriction $T|_U$ is a well-defined linear operator on $U$.
\end{solution}

\begin{problem}[Operator synthesis]\label{prob:i05-dossier-12}
Why does specifying values on a spanning list fail to define a linear map unless all dependence relations are respected?
\end{problem}
\begin{solution}
If $\sum a_iv_i=0$ is a relation in the spanning list, linearity requires $\sum a_iT(v_i)=0$. Arbitrary assigned images may violate this condition, giving contradictory values for the same vector. A basis avoids the problem because it has no nontrivial relations.
\end{solution}

\section{Exercises with complete solutions}

\begin{exercise}\label{exr:i05-01}
Show that $T(x,y)=(x+2y,3x-y)$ is linear.
\end{exercise}
\begin{hint}
Check \(T(u+v)=T(u)+T(v)\) and \(T(\lambda u)=\lambda T(u)\) separately; one failure is enough.
\end{hint}
\begin{solution}
Each output coordinate is a homogeneous linear expression in $x,y$, so direct substitution verifies preservation of linear combinations.
\end{solution}

\begin{exercise}\label{exr:i05-02}
Is $T(x,y)=(x+1,y)$ linear?
\end{exercise}
\begin{hint}
Write each input vector in the chosen basis and use linearity to extend the prescribed basis values.
\end{hint}
\begin{solution}
No. A linear map must send $0$ to $0$, but this map sends $(0,0)$ to $(1,0)$.
\end{solution}

\begin{exercise}\label{exr:i05-03}
Construct the unique linear map with $T(e_1)=(1,1)$ and $T(e_2)=(2,0)$.
\end{exercise}
\begin{hint}
To construct the map, choose images of basis vectors first; linearity then forces every other value.
\end{hint}
\begin{solution}
For $(x,y)=xe_1+ye_2$, $T(x,y)=x(1,1)+y(2,0)=(x+2y,x)$.
\end{solution}

\begin{exercise}\label{exr:i05-04}
Show that composition of linear maps is linear.
\end{exercise}
\begin{hint}
For a composition, compute the inner map first and keep track of which space each intermediate vector lies in.
\end{hint}
\begin{solution}
Apply the inner map to a linear combination, then use linearity of the outer map.
\end{solution}

\begin{exercise}\label{exr:i05-05}
Prove that two linear maps agreeing on a basis agree everywhere.
\end{exercise}
\begin{hint}
To test invertibility, verify both \(ST=I\) and \(TS=I\); one-sided cancellation is not enough in an arbitrary setting.
\end{hint}
\begin{solution}
Every vector is a linear combination of basis vectors, and both maps distribute over that combination.
\end{solution}

\begin{exercise}\label{exr:i05-06}
Give a nonzero nilpotent operator on $\mathbb R^2$.
\end{exercise}
\begin{hint}
Compare the effect of the two maps on a basis; equality on a basis implies equality everywhere.
\end{hint}
\begin{solution}
Take $N(x,y)=(y,0)$. Then $N\ne0$ but $N^2=0$.
\end{solution}

\begin{exercise}\label{exr:i05-07}
Show that $\mathcal L(V,W)$ is a vector space.
\end{exercise}
\begin{hint}
For a geometric transformation, compute what it does to the standard basis before writing a general formula.
\end{hint}
\begin{solution}
Verify the vector-space axioms pointwise; the zero vector is the zero map.
\end{solution}

\begin{exercise}\label{exr:i05-08}
Explain why a bijective nonlinear map need not be an isomorphism of vector spaces.
\end{exercise}
\begin{hint}
If a constant term survives when the input is zero, the map cannot be linear.
\end{hint}
\begin{solution}
An isomorphism must preserve addition and scalar multiplication; bijectivity alone preserves only set structure.
\end{solution}

\section{Graded supplementary exercises}
The following exercises extend the original exercise set without replacing it. They are grouped by mathematical role and increase in synthesis.

\subsection*{Standard computations}

\begin{exercise}[Formula from basis images]\label{exr:i05-expand-01}
If \(T(e_1)=(1,2)\), \(T(e_2)=(-1,3)\), find \(T(x,y)\).
\end{exercise}
\begin{hint}
Use \(T(xe_1+ye_2)=xT(e_1)+yT(e_2)\).
\end{hint}
\begin{solution}
\(T(x,y)=(x-y,2x+3y)\).
\end{solution}

\begin{exercise}[Composition]\label{exr:i05-expand-02}
For \(T(x,y)=(x+y,y)\), \(S(u,v)=(u-v,v)\), compute \(S\circ T\).
\end{exercise}
\begin{hint}
Substitute \(T(x,y)\) into \(S\).
\end{hint}
\begin{solution}
\((S\circ T)(x,y)=(x,y)\), so \(S=T^{-1}\).
\end{solution}

\begin{exercise}[Nilpotent power]\label{exr:i05-expand-03}
For \(N(x,y,z)=(y,z,0)\), compute \(N^2,N^3\).
\end{exercise}
\begin{hint}
Apply the same formula repeatedly.
\end{hint}
\begin{solution}
\(N^2(x,y,z)=(z,0,0)\) and \(N^3=0\).
\end{solution}

\begin{exercise}[Projection]\label{exr:i05-expand-04}
For \(P(x,y,z)=(x,y,0)\), find all fixed vectors.
\end{exercise}
\begin{hint}
Solve \(P(v)=v\).
\end{hint}
\begin{solution}
The fixed vectors are exactly \(z=0\), the \(xy\)-plane.
\end{solution}

\begin{exercise}[Evaluation]\label{exr:i05-expand-05}
On \(\mathcal P_2\), compute \(E_2(1-3x+x^2)\).
\end{exercise}
\begin{hint}
Substitute \(x=2\).
\end{hint}
\begin{solution}
\(1-6+4=-1\).
\end{solution}

\subsection*{Proofs}

\begin{exercise}[Basis determination]\label{exr:i05-expand-06}
Prove two linear maps agreeing on a basis agree everywhere.
\end{exercise}
\begin{hint}
Expand an arbitrary vector in the basis.
\end{hint}
\begin{solution}
Linearity makes both maps the same linear combination of identical basis images.
\end{solution}

\begin{exercise}[Composition linear]\label{exr:i05-expand-07}
Prove the composite of two linear maps is linear.
\end{exercise}
\begin{hint}
Pass a general linear combination through the inner map and then the outer map.
\end{hint}
\begin{solution}
\((ST)(av+bw)=S(aTv+bTw)=aSTv+bSTw\).
\end{solution}

\begin{exercise}[Inverse linear]\label{exr:i05-expand-08}
Prove the inverse of a bijective linear map is linear.
\end{exercise}
\begin{hint}
Write \(y_i=T(x_i)\) and pull a combination back through \(T\).
\end{hint}
\begin{solution}
\(T^{-1}(ay_1+by_2)=T^{-1}T(ax_1+bx_2)=ax_1+bx_2\).
\end{solution}

\begin{exercise}[Operator space]\label{exr:i05-expand-09}
Prove \(\mathcal L(V,W)\) is closed under linear combinations.
\end{exercise}
\begin{hint}
Check \((aS+bT)(cv+dw)\).
\end{hint}
\begin{solution}
Pointwise operations preserve the linearity identity, so \(aS+bT\) is linear.
\end{solution}

\subsection*{Counterexamples}

\begin{exercise}[Translation]\label{exr:i05-expand-10}
Show \(F(x,y)=(x+1,y)\) is not linear.
\end{exercise}
\begin{hint}
Test the zero vector.
\end{hint}
\begin{solution}
\(F(0,0)=(1,0)\neq0\).
\end{solution}

\begin{exercise}[Quadratic component]\label{exr:i05-expand-11}
Show \(F(x,y)=(x,y^2)\) is not linear.
\end{exercise}
\begin{hint}
Test homogeneity with scalar \(2\).
\end{hint}
\begin{solution}
\(F(2x,2y)=(2x,4y^2)\neq2F(x,y)\) when \(y\neq0\).
\end{solution}

\begin{exercise}[Noncommuting maps]\label{exr:i05-expand-12}
Give two linear maps on \(\mathbb R^2\) that do not commute.
\end{exercise}
\begin{hint}
Use a projection and a quarter-turn.
\end{hint}
\begin{solution}
With \(P(x,y)=(x,0)\), \(R(x,y)=(-y,x)\), \(RP(1,1)=(0,1)\) but \(PR(1,1)=(-1,0)\).
\end{solution}

\subsection*{Applications}

\begin{exercise}[Reflection]\label{exr:i05-expand-13}
Write the reflection across the \(x\)-axis as a linear map and describe its square.
\end{exercise}
\begin{hint}
Flip the sign of the second coordinate.
\end{hint}
\begin{solution}
\(R(x,y)=(x,-y)\), and \(R^2=I\).
\end{solution}

\begin{exercise}[Differentiation]\label{exr:i05-expand-14}
Why is differentiation a linear map \(\mathcal P_3\to\mathcal P_2\)?
\end{exercise}
\begin{hint}
Use \((ap+bq)'=ap'+bq'\).
\end{hint}
\begin{solution}
Differentiation preserves all linear combinations and lowers degree by one.
\end{solution}

\subsection*{Challenges}

\begin{exercise}[Images on dependent generators]\label{exr:i05-expand-15}
Can one define a linear map by prescribing arbitrary images of \(v_1,v_2,v_1+v_2\)?
\end{exercise}
\begin{hint}
The dependence relation must be preserved.
\end{hint}
\begin{solution}
Only if the third prescribed image equals the sum of the first two; otherwise linearity gives a contradiction.
\end{solution}

\begin{exercise}[Idempotent decomposition]\label{exr:i05-expand-16}
If \(P^2=P\), prove every \(v\) decomposes as \(v=Pv+(v-Pv)\) with first term in \(\operatorname{im}P\) and second in \(\ker P\).
\end{exercise}
\begin{hint}
Apply \(P\) to \(v-Pv\).
\end{hint}
\begin{solution}
\(P(v-Pv)=Pv-P^2v=0\), while \(Pv\in\operatorname{im}P\); the displayed equality is immediate.
\end{solution}

\section*{Chapter summary}
Linear transformations are the morphisms of vector spaces: they preserve exactly the operations that define linear structure. Once linearity is recognized, a map is determined by its action on a basis, compositions remain linear, and apparently different formulas become instances of the same operator calculus.
The important habit is to move fluently between invariant statements and concrete coordinates while remembering which conclusions depend on finite dimensionality, the scalar field, or the inner product.
