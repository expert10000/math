\section*{AG8 Problem 3 split}
Problem 3 asks for counterexamples to parts (a), (c), and (d) of Problem 2.  The part-(d) counterexample belongs
uniquely here.  It is split explicitly as \texttt{AG8-P3d -> VI.30.P2}:
\[
X=\Spec k\sqcup\mathbb A^1_k,\qquad U=\Spec k,
\qquad \dim U=0<1=\dim X.

The parent \texttt{AG8-P3} remains pending only for VI/31--VI/32, where the codimension-additivity and local-dimension
counterexamples belong.  This keeps every substantive legacy subproblem at exactly one canonical destination.

\section*{Transcendence-degree boundary}

VI/30 uses that result to prove the dimension theorem $\dim X=\operatorname{trdeg}_kK(X)$ for varieties.  This is a
new dimension-side theorem in the canonical exposition, not a second legacy destination for \texttt{AG8-P2c}.

\section*{Mathematical hypothesis audit}
The source theorem $\dim U=\dim X$ is stated for varieties.  VI/30 preserves that hypothesis.  It does not replace it
by the false assertion that every irreducible or every Noetherian integral scheme has open-dimension invariance.
The canonical counterexample $\Spec k[x,y]_{(x)}$ with $D(x)$ of dimension zero records this boundary explicitly.
