\begin{problem}[Affine neighborhood calculations]\label{prob:vi18-p15}
Given $\mfp\in\Spec A$ and $a/s\in A_{\mfp}$, construct a distinguished affine neighborhood on which the germ is represented by a regular section.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
This problem consolidates the local fractions aspect of affine geometry and turns a structural statement into a reusable calculation.

\paragraph{Useful ideas before starting.}
Choose $s\notin\mfp$ and use $D(s)$.

\paragraph{Guided hints.}
\begin{enumerate}
\item Choose $s\notin\mfp$ and use $D(s)$.
\item Reduce the statement to a ring-theoretic property whenever possible.
\item Translate the result back into topology, sheaves, or local rings so that all affine-scheme layers are visible.
\end{enumerate}

\begin{solution}
Write the germ as $a/s\in A_{\mathfrak p}$ with $s\notin\mathfrak p$. Then $\mathfrak p\in D(s)$, and $D(s)$ is an affine neighborhood of $\mathfrak p$:
\[
D(s)\cong\Spec A_s.
\]
The fraction $a/s$ is an element of $A_s=\Gamma(D(s),\mathcal O_X)$, so it defines a regular section on this distinguished neighborhood.

Under the canonical map
\[
A_s\longrightarrow A_{\mathfrak p},
\]
the section $a/s$ maps to the original germ. Thus every element of the local ring is represented by a regular section on some affine neighborhood. If one starts with a different representative of the same germ, the localization equality criterion shows that the two representatives agree after possibly shrinking to a smaller distinguished neighborhood.
\end{solution}


\paragraph{What happened mathematically.}
The calculation illustrates that global affine geometry is controlled by commutative algebra once the structure sheaf is kept in view.

\paragraph{Extensions.}
Vary the ring by products, quotients, localizations, arithmetic examples, or nilpotent thickenings and repeat the same dictionary.
