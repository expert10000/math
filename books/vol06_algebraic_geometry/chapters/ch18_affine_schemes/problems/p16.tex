\begin{problem}[Residue fields across an affine scheme]\label{prob:vi18-p16}
For $A=\mathbb Z[t]$, compute residue fields at $(0)$, $(p)$, and $(p,t-a)$, explaining how the fields vary with specialization.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
This problem consolidates the residue fields aspect of affine geometry and turns a structural statement into a reusable calculation.

\paragraph{Useful ideas before starting.}
Use $\kappa(\mfp)=\Frac(A/\mfp)$.

\paragraph{Guided hints.}
\begin{enumerate}
\item Use $\kappa(\mfp)=\Frac(A/\mfp)$.
\item Reduce the statement to a ring-theoretic property whenever possible.
\item Translate the result back into topology, sheaves, or local rings so that all affine-scheme layers are visible.
\end{enumerate}

\begin{solution}
Let $A=\mathbb Z[t]$. At the generic prime $(0)$ the quotient $A/(0)$ is the domain $\mathbb Z[t]$, so
\[
\kappa((0))=\operatorname{Frac}(\mathbb Z[t])=\mathbb Q(t).
\]

For the prime $(p)$, the quotient is
\[
A/(p)\cong\mathbb F_p[t],
\]
which is again a domain. Hence
\[
\kappa((p))=\operatorname{Frac}(\mathbb F_p[t])=\mathbb F_p(t).
\]

Finally, for a maximal ideal $(p,t-a)$, where $a$ denotes a residue class modulo $p$,
\[
A/(p,t-a)\cong\mathbb F_p,
\]
so
\[
\kappa((p,t-a))=\mathbb F_p.
\]
The chain
\[
(0)\subset(p)\subset(p,t-a)
\]
exhibits specialization from a characteristic-zero generic point to a characteristic-$p$ generic point of the fiber and then to a closed point. The residue fields accordingly change from $\mathbb Q(t)$ to $\mathbb F_p(t)$ to $\mathbb F_p$. These are residue fields of different local rings; one should not expect a single fixed field of values over the whole scheme.
\end{solution}


\paragraph{What happened mathematically.}
The calculation illustrates that global affine geometry is controlled by commutative algebra once the structure sheaf is kept in view.
