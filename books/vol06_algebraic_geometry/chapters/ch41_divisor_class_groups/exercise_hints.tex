% VI/41 exercise hints — canonical exercise order preserved.
% VI41-EXERCISE-HINT-01
\paragraph{Hint for Exercise VI.41.01.}
For reflexivity use \(\operatorname{div}(1)=0\); for symmetry replace \(f\) by \(f^{-1}\); for transitivity multiply the two witnessing rational functions.

% VI41-EXERCISE-HINT-02
\paragraph{Hint for Exercise VI.41.02.}
The zero element of a quotient group \(G/H\) is the coset \(H\) itself.

% VI41-EXERCISE-HINT-03
\paragraph{Hint for Exercise VI.41.03.}
Use that \(k[t]\) is a PID, hence a UFD, and invoke the class-group criterion.

% VI41-EXERCISE-HINT-04
\paragraph{Hint for Exercise VI.41.04.}
Polynomial rings over a field are UFDs.

% VI41-EXERCISE-HINT-05
\paragraph{Hint for Exercise VI.41.05.}
If \(\operatorname{div}(f)=[\mathfrak p]\), inspect every height-one valuation of \(f\) and of \(a/f\) for \(a\in\mathfrak p\).

% VI41-EXERCISE-HINT-06
\paragraph{Hint for Exercise VI.41.06.}
Use the localization exact sequence: a quotient of the zero class group is zero.

% VI41-EXERCISE-HINT-07
\paragraph{Hint for Exercise VI.41.07.}
Compute \(A/(x,z)\) and \(A/(y,z)\) and compare dimensions.

% VI41-EXERCISE-HINT-08
\paragraph{Hint for Exercise VI.41.08.}
At \((x,z)\), \(y\) is a unit and \(x=z^2/y\).

% VI41-EXERCISE-HINT-09
\paragraph{Hint for Exercise VI.41.09.}
The equation \(z=0\) forces \(xy=0\); determine the two height-one components and their orders.

% VI41-EXERCISE-HINT-10
\paragraph{Hint for Exercise VI.41.10.}
Subtract the divisor of \(z\) from the divisor of \(x\).

% VI41-EXERCISE-HINT-11
\paragraph{Hint for Exercise VI.41.11.}
After inverting \(x\), solve for \(y=z^2/x\).

% VI41-EXERCISE-HINT-12
\paragraph{Hint for Exercise VI.41.12.}
Show \(A_x\) is factorial and identify the unique height-one prime containing \(x\).

% VI41-EXERCISE-HINT-13
\paragraph{Hint for Exercise VI.41.13.}
Use the connected positive grading and compare highest homogeneous degrees in a product \(uv=1\).

% VI41-EXERCISE-HINT-14
\paragraph{Hint for Exercise VI.41.14.}
Use the \(x\)-adic valuation of the rational function field \(k(x,z)\).

% VI41-EXERCISE-HINT-15
\paragraph{Hint for Exercise VI.41.15.}
Prove generation by \([L]\), the relation \(2[L]=0\), and nontriviality separately.

% VI41-EXERCISE-HINT-16
\paragraph{Hint for Exercise VI.41.16.}
Removing the vertex removes no codimension-one component.

% VI41-EXERCISE-HINT-17
\paragraph{Hint for Exercise VI.41.17.}
Smoothness is local; principalness of a global divisor is global.

% VI41-EXERCISE-HINT-18
\paragraph{Hint for Exercise VI.41.18.}
The complement of \(D_+(x_0)\) is one hyperplane and the open set is affine space.

% VI41-EXERCISE-HINT-19
\paragraph{Hint for Exercise VI.41.19.}
Represent a rational function by homogeneous forms of the same degree and compare zero and pole degrees.

% VI41-EXERCISE-HINT-20
\paragraph{Hint for Exercise VI.41.20.}
Combine generation by \(H\) with the degree-zero property for principal divisors.

% VI41-EXERCISE-HINT-21
\paragraph{Hint for Exercise VI.41.21.}
Compare \(F\) with \(\ell^d\) for a linear form \(\ell\).

% VI41-EXERCISE-HINT-22
\paragraph{Hint for Exercise VI.41.22.}
A codimension-one irreducible closed subset cannot lie inside a codimension-at-least-two complement.

% VI41-EXERCISE-HINT-23
\paragraph{Hint for Exercise VI.41.23.}
The generic point, function field, and corresponding height-one local rings do not change.

% VI41-EXERCISE-HINT-24
\paragraph{Hint for Exercise VI.41.24.}
Use \(2L=\operatorname{div}(x)\) together with the fact from VI/40 that \(L\) is not Cartier at the vertex.
