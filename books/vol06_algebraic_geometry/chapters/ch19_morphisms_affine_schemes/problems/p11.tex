\begin{problem}[Affine-scheme isomorphisms are ring isomorphisms]\label{prob:vi19-p11}
Prove $\Spec A\cong\Spec B$ as affine schemes if and only if $A\cong B$ as rings, and show a given affine morphism is an isomorphism iff its global pullback is.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
This turns geometric isomorphism testing into algebra.

\paragraph{Useful ideas before starting.}
Use the affine Hom correspondence and global recovery.

\paragraph{Guided hints.}
\begin{enumerate}
\item A ring inverse gives a reversed scheme inverse.
\item A scheme inverse gives inverse maps on global sections.
\end{enumerate}

\begin{solution}
If $\varphi:A\to B$ is an isomorphism with inverse $\psi$, then contravariant functoriality gives
\[
\Spec(\varphi)\circ\Spec(\psi)=\operatorname{id},\qquad
\Spec(\psi)\circ\Spec(\varphi)=\operatorname{id}.
\]
Conversely, if an affine morphism $f$ has inverse $g$, then the induced maps on global sections compose to identities.  Therefore $f^\sharp_X:A\to B$ is an isomorphism.  Applying this to an arbitrary affine-scheme isomorphism proves the object-level criterion.
\end{solution}

\paragraph{What happened mathematically.}
Affine geometry remembers the entire coordinate ring, including nilpotents, through its sheaf.

\paragraph{Extensions.}
Compare $\Spec k$ with the dual-number point.
