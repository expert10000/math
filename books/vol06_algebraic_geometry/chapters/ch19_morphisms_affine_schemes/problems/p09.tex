\begin{problem}[Residue fields under affine morphisms]\label{prob:vi19-p09}
Let $f=\Spec(\varphi):\Spec B\to\Spec A$. For $\mfp\in\Spec B$, prove the local stalk map induces a field homomorphism $\kappa(f(\mfp))\to\kappa(\mfp)$ and compute it for an evaluation map $k[t]\to K$, $t\mapsto a$.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
A scheme morphism transports not only points but also their fields of values.

\paragraph{Useful ideas before starting.}
Quotient the local stalk map by maximal ideals.

\paragraph{Guided hints.}
\begin{enumerate}
\item Set $\mfq=\varphi^{-1}(\mfp)$.
\item Use locality to descend $A_\mfq\to B_\mfp$.
\item For evaluation, identify the kernel and residue fields.
\end{enumerate}

\begin{solution}
The local map $A_\mfq\to B_\mfp$ sends $\mfq A_\mfq$ into $\mfp B_\mfp$, so it descends to
\[
\kappa(\mfq)=A_\mfq/\mfq A_\mfq\longrightarrow B_\mfp/\mfp B_\mfp=\kappa(\mfp).
\]
For $k[t]\to K$, $t\mapsto a$, the unique point of $\Spec K$ maps to the prime $\ker(k[t]\to K)$.  If $a\in k$ and the map fixes $k$, this is $(t-a)$ and the residue-field map is the canonical $k\to K$.
\end{solution}

\paragraph{What happened mathematically.}
Residue-field maps encode arithmetic information invisible in the underlying continuous map.

\paragraph{Extensions.}
Use a non-rational point of $\Spec k[t]$.
