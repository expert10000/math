\begin{problem}[Sections inject into $K(X)$]\label{prob:vi27-p07}
Prove that $\OO_X(U)\to K(X)$ is injective for every nonempty open $U$ of an integral scheme.
\par\smallskip\noindent\textit{Provenance.} Canonical VI/27 dossier.
\end{problem}
\begin{solution}
If a section has zero germ at $\eta$, it vanishes on some neighborhood $V$ of $\eta$.  The nonvanishing locus of the section is open.  If nonempty, it would meet $V$ because $U$ is irreducible, contradicting vanishing there.  Hence the section is zero.
\end{solution}
