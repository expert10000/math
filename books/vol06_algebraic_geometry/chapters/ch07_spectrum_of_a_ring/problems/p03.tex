\begin{problem}[Closure, specialization, and arbitrary subsets]
Let $S\subseteq\Spec A$.  Prove
\[
\overline S
=
V\!\left(\bigcap_{\mathfrak p\in S}\mathfrak p\right).
\]
Deduce the point-closure formula and characterize specialization in terms of prime inclusion.
\end{problem}

\paragraph{Why this problem matters.}
This formula converts a topological closure operation into a purely algebraic intersection.

\paragraph{Useful ideas before starting.}
A closed set $V(J)$ contains $S$ iff $J$ is contained in every prime of $S$.

\paragraph{Guided hints.}
Find the largest ideal $J$ for which $S\subseteq V(J)$; inclusion reversal then turns it into
the smallest closed set containing $S$.

\begin{solution}
Set
\[
I(S)=\bigcap_{\mathfrak p\in S}\mathfrak p.
\]
If $V(J)$ contains $S$, then $J\subseteq\mathfrak p$ for every $\mathfrak p\in S$, so
$J\subseteq I(S)$.  Hence
\[
V(I(S))\subseteq V(J).
\]
Since $I(S)\subseteq\mathfrak p$ for every $\mathfrak p\in S$, the set $V(I(S))$ itself
contains $S$.  It is therefore the closure.

For $S=\{\mathfrak p\}$,
\[
\overline{\{\mathfrak p\}}=V(\mathfrak p).
\]
Thus
\[
\mathfrak q\in\overline{\{\mathfrak p\}}
\iff
\mathfrak p\subseteq\mathfrak q.
\]
\end{solution}

\paragraph{What happened mathematically.}
Specialization is simply ideal enlargement.  A topological relation between points is encoded
by the partial order of prime ideals.

\paragraph{Extensions.}
Show that a subset is dense iff the intersection of its prime ideals is contained in the
nilradical, equivalently has radical equal to $\sqrt{(0)}$.

\paragraph{Provenance.}
New synthesis expanding the legacy point-closure discussions.
