\begin{problem}[Derivative image on $S^1$]\label{prob:vi15-p17}
Show that $d:\mathcal C^\infty\to\Omega^1$ has image sheaf all of $\Omega^1$, but on global sections its image consists of one-forms with integral zero.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
A differential-geometric example isolates the same local/global image distinction.

\paragraph{Useful ideas.}
Translate the sheaf statement to local representatives or stalks whenever possible.  Keep track of whether the construction is sectionwise or requires sheafification.

\paragraph{Guided hints.}
Local primitives exist; globally use $\int_{S^1}dF=0$ and construct a primitive when the integral vanishes.

\begin{solution}
Locally on a coordinate interval, every smooth one-form has the form $a(t)\,dt$. Fix $t_0$ and define
\[
F(t)=\int_{t_0}^t a(u)\,du.
\]
Then $dF=a(t)\,dt$. Thus every germ of a one-form has a local primitive, so the image sheaf of
\[
d:\mathcal C^\infty\to\Omega^1
\]
is all of $\Omega^1$.

For global sections on $S^1=\mathbb R/\mathbb Z$, write $\omega=a(t)dt$ with $a$ periodic. If $\omega=dF$ for a periodic smooth function $F$, then
\[
\int_{S^1}\omega=F(1)-F(0)=0.
\]
Conversely, if $\int_0^1a(t)dt=0$, put $F(t)=\int_0^t a(u)du$. Then
\[
F(t+1)-F(t)=\int_t^{t+1}a(u)du=\int_0^1a(u)du=0,
\]
so $F$ is periodic and descends to $S^1$, with $dF=\omega$. Therefore the global sectionwise image is exactly the one-forms of integral zero.
\end{solution}

\paragraph{What happened mathematically.}
A differential-geometric example isolates the same local/global image distinction.

\paragraph{Extensions.}
Formulate the same statement for sheaves of modules.  Where meaningful, test the statement on a discrete space and then on the exponential-map example to see the difference between sectionwise and local behavior.
