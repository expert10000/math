\begin{problem}[A strict quotient-presheaf example]\label{prob:vi15-p6}
Using the same exponential morphism, show that $\mathcal C^0_{\mathbb R}/\underline{\mathbb Z}\cong\mathcal C^0_{S^1}$ as sheaves, while the sectionwise quotient over $S^1$ does not contain the degree-one map.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
The missing global quotient section is created by sheafification from local lifts.

\paragraph{Useful ideas.}
Translate the sheaf statement to local representatives or stalks whenever possible.  Keep track of whether the construction is sectionwise or requires sheafification.

\paragraph{Guided hints.}
Combine the kernel calculation with local surjectivity and the quotient stalk theorem.

\begin{solution}
For the exponential morphism $E$, a local section $f$ lies in the kernel exactly when $e^{2\pi if}=1$, hence when $f$ is integer-valued. A continuous integer-valued function is locally constant, so
\[
\ker E=\underline{\mathbb Z}.
\]
By Problem VI.15.P5, the image sheaf of $E$ is the whole target. The coimage-image theorem therefore gives
\[
\mathcal C^0_{\mathbb R}/\underline{\mathbb Z}
\cong
\im E
=
\mathcal C^0_{S^1}.
\]

On global sections, however, the naive quotient consists of global real-valued functions modulo global locally constant integer-valued functions. Under exponential it produces only circle-valued maps admitting a global continuous argument. The degree-one section $z\mapsto z$ has no global continuous argument by Problem VI.15.P5. Thus the sectionwise quotient over $S^1$ is strictly too small, while its sheafification contains the missing section assembled from local arguments whose differences are integers.
\end{solution}

\paragraph{What happened mathematically.}
The missing global quotient section is created by sheafification from local lifts.

\paragraph{Extensions.}
Formulate the same statement for sheaves of modules.  Where meaningful, test the statement on a discrete space and then on the exponential-map example to see the difference between sectionwise and local behavior.
