\begin{problem}[Challenge: dense opens and component-generic points]
Let $X$ be a topological space whose irreducible components $C_i$ all have generic points
$\eta_i$.  Let $U\subseteq X$ be open.  Prove that
\[
U\text{ is dense in }X
\quad\Longleftrightarrow\quad
\eta_i\in U\text{ for every irreducible component }C_i.
\]
Apply this to $X=\Spec A$.
\end{problem}

\paragraph{Why this challenge matters.}
A potentially huge density question reduces to checking a distinguished set of generic
points.

\paragraph{Useful ideas.}
An open set meets an irreducible component iff it contains that component's generic point.
A subset is dense iff it meets every nonempty open subset; equivalently, its closure
contains every irreducible component.

\paragraph{Guided hints.}
If some $\eta_i\notin U$, then $U\cap C_i=\varnothing$.  Conversely, if every $\eta_i$ lies
in $U$, then $U$ meets every component densely.

\begin{solution}
Suppose first that $U$ is dense.  Then $U\cap C_i$ is a nonempty open subset of each
irreducible component $C_i$; otherwise the closed set $X\setminus U$ would contain the
whole component.  Every nonempty open subset of $C_i$ contains its generic point, so
\[
\eta_i\in U.
\]

Conversely, suppose every $\eta_i\in U$.  Then for each component,
\[
\overline{U\cap C_i}^{\,C_i}=C_i
\]
because $U\cap C_i$ contains the generic point.  Hence the closure of $U$ in $X$ contains
every $C_i$.  Since the union of all irreducible components is $X$, we obtain
\[
\overline U=X.
\]
For $X=\Spec A$, the $\eta_i$ are precisely the minimal prime ideals.
\end{solution}

\paragraph{What happened mathematically.}
Minimal primes become a finite or infinite checklist for density of opens.

\paragraph{Extensions.}
For a Noetherian spectrum, use finiteness of irreducible components to obtain a finite
generic-point test.

\paragraph{Provenance.}
New challenge built from the legacy irreducibility and generic-point material.
