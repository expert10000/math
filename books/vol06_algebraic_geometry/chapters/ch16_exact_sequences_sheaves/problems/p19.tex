\begin{problem}[Local splitting versus global splitting]\label{prob:vi16-p19}
Suppose a short exact sequence admits splittings after restricting to an open cover.  Prove that it is locally a direct sum.  Show that a global splitting exists exactly when the local splittings can be modified to agree on overlaps.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
It separates local algebra from the global gluing obstruction.

\paragraph{Useful ideas.}
On overlaps, the difference of two splittings lands in the kernel $\F'$.

\paragraph{Guided hints.}
\begin{enumerate}
\item Use P13 on each open set.
\item If $s_i,s_j$ are splittings, compute $q(s_i-s_j)$.
\item Agreement after modifications is exactly the sheaf gluing condition for a global splitting.
\end{enumerate}

\begin{solution}
On each $U_i$, P13 gives $\F|_{U_i}\cong\F'|_{U_i}\oplus\F''|_{U_i}$.  On $U_i\cap U_j$,
$q(s_i-s_j)=\id-\id=0$, so $s_i-s_j$ factors through $\F'$.  If one can change the $s_i$ by morphisms into $\F'$ so that these differences vanish on overlaps, the corrected splittings glue to a global morphism $s:\F''\to\F$ with $qs=\id$.  Conversely any global splitting restricts to compatible local splittings.
\end{solution}

\paragraph{What happened mathematically.}
The obstruction to global splitting lives in overlap data with values in the kernel sheaf, foreshadowing cohomology.

\paragraph{Extensions.}
Formulate the overlap differences as a Cech 1-cocycle once VI/47 is available.
