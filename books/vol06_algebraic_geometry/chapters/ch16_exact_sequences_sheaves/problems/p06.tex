\begin{problem}[Global sections are left exact but not right exact]\label{prob:vi16-p06}
Given a short exact sequence $0\to\F'\to\F\to\F''\to0$, prove $0\to\F'(U)\to\F(U)\to\F''(U)$ is exact.  Then give a concrete example where the last map is not surjective.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
This is the gateway to sheaf cohomology but stops before consuming the dedicated later corpus problem.

\paragraph{Useful ideas.}
Use the sectionwise kernel for the left part and the exponential sequence for the counterexample.

\paragraph{Guided hints.}
\begin{enumerate}
\item Kernels are computed sectionwise.
\item Exactness identifies $\F'$ with the kernel sheaf.
\item Use the identity map on $S^1$ for failure of surjectivity.
\end{enumerate}

\begin{solution}
Injectivity of $\F'(U)\to\F(U)$ is immediate.  A section of $\F(U)$ mapping to zero belongs to the kernel sheaf, which is $\F'$, hence comes from $\F'(U)$.  Thus the sequence is exact at the first two terms.  For the continuous exponential short exact sequence on $S^1$, the map on global sections is not onto because the identity map has no global argument.
\end{solution}

\paragraph{What happened mathematically.}
The section functor preserves kernels but can lose epimorphisms.  That failure is exactly why higher cohomology enters later.

\paragraph{Extensions.}
Ask when special classes of sheaves make global sections exact.
