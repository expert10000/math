\begin{problem}[Challenge 1: Dimension filtration]\label{chal:vi29-01}
For a Noetherian affine scheme $X=\Spec A$, organize points by height and explain how the filtration by possible heights reflects specialization chains.  Give the filtration explicitly for $\Spec k[x,y]$.

\textbf{Hint.} Separate generic points (height $0$), codimension-one points (height $1$), and closed points of height $2$; justify each layer using prime chains.
\end{problem}
