\begin{problem}[Reducedness is local]
Prove that the following are equivalent:
\begin{enumerate}
\item $A$ is reduced;
\item $A_{\mathfrak p}$ is reduced for every prime $\mathfrak p$;
\item there is a finite principal-open cover $\Spec A=\bigcup_iD(f_i)$ with each $A_{f_i}$ reduced.
\end{enumerate}
\end{problem}
\paragraph{Why this problem matters.}
Reducedness is a local geometric property, even though its definition is global in the ring.
\paragraph{Useful ideas before starting.}
Localization preserves reducedness.  For the converse, use the fact that an element that
vanishes in every localization at a prime is zero.
\paragraph{Guided hints.}
If $a\neq0$, its annihilator is proper.  Put that annihilator inside a prime ideal.
\begin{solution}
Reducedness localizes, so (1) implies (2), and (2) implies the existence of local reduced
neighborhoods.  For (2)$\Rightarrow$(1), if $a^n=0$, then $a/1=0$ in every
$A_{\mathfrak p}$.  If $a\neq0$, choose a prime $\mathfrak p\supseteq\operatorname{Ann}(a)$.
The equality $a/1=0$ would give $s\notin\mathfrak p$ with $sa=0$, contradicting
$s\in\operatorname{Ann}(a)\subseteq\mathfrak p$.  Hence $a=0$.
For a finite principal cover, the argument in the chapter shows that a nilpotent element
annihilated locally is annihilated by an ideal with radical $(1)$, hence is zero.
\end{solution}
\paragraph{What happened mathematically.}
Nilpotents cannot hide simultaneously from all neighborhoods of every point.
