\begin{problem}[Affine integral criterion]
Prove that for a commutative ring $A$,
\[
A\text{ is a domain}
\iff
A\text{ is reduced and }\Spec A\text{ is irreducible}.
\]
Give examples showing that neither ``reduced'' nor ``irreducible spectrum'' alone suffices.
\end{problem}
\paragraph{Why this problem matters.}
It cleanly separates the algebraic and topological halves of integrality.
\paragraph{Useful ideas before starting.}
$\Spec A$ is irreducible exactly when $\Nil(A)$ is prime.
\paragraph{Guided hints.}
If $A$ is reduced, $\Nil(A)=0$.  Combine this with irreducibility.
\begin{solution}
If $A$ is a domain, then it is reduced and $(0)$ is prime, so $\Spec A$ is irreducible.
Conversely, if $A$ is reduced then $\Nil(A)=0$.  If $\Spec A$ is irreducible, its
nilradical is prime.  Hence $(0)$ is prime and $A$ is a domain.
The ring $k[x,y]/(xy)$ is reduced but has reducible spectrum; the ring
$k[x,y]/(x^2)$ has irreducible spectrum but is nonreduced.
\end{solution}
\paragraph{What happened mathematically.}
A domain is exactly ``no infinitesimal nilpotents'' plus ``one irreducible component.''
\paragraph{Extensions.}

\paragraph{Provenance.}
New affine formulation.  Legacy \emph{Theory of Algebraic Geometry 5}, Problem 3 asks the
full scheme-level theorem ``integral iff reduced and irreducible''; that problem is retained
for VI/27 rather than duplicated here.
