\subsection*{VI.22.P18: Closedness is not determined by point image alone}
\begin{problem}\label{prob:vi22-p18}
Explain why knowing only the subset $|Z|\subseteq|X|$ cannot determine a closed subscheme structure.
\par\textbf{Solution.} In an affine chart, $V(I)$ depends only on $\sqrt I$, whereas the scheme structure uses $A/I$.  Different ideals with the same radical, such as $(x)$ and $(x^2)$, yield the same point subset but different structure sheaves.
\end{problem}
