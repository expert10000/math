% Problem dossier: VI.02.P6
\subsection*{Problem VI.02.P6 --- Quasi-compactness from finite generation}
\label{prob:vi02-p6}

\paragraph{Problem.}
Prove that every open cover of \(\mathbb A_k^n\) has a finite subcover.  More generally,
prove the same for every affine algebraic set \(X\subseteq\mathbb A_k^n\).  You may use
Hilbert's basis theorem.

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
Affine algebraic spaces are topologically quasi-compact even when they are enormous and
non-Hausdorff.  The reason is algebraic finite generation, not metric boundedness.

\paragraph{Useful ideas before starting.}
Refine the cover by principal opens.  If \(\set{D_X(f_\lambda)}\) covers \(X\), then the
common zero locus \(V_X(f_\lambda:\lambda)\) is empty.  Apply finite generation to the ideal
generated by all \(f_\lambda\).

\paragraph{Guided hints.}
\textbf{Hint 1.} Principal opens form a basis, so reduce to a principal-open cover.

\textbf{Hint 2.} Let \(J\) be the ideal generated by all covering polynomials.  Hilbert's
basis theorem gives finitely many generators, each of which uses only finitely many of the
original \(f_\lambda\).

\paragraph{Solution.}
Refine the given cover to principal opens \(D_X(f_\lambda)\).  Their union is \(X\), so
\[
\bigcap_\lambda V_X(f_\lambda)=\varnothing.
\]
Let \(J=(f_\lambda:\lambda)\).  By Hilbert's basis theorem, \(J\) is generated by finitely
many elements \(g_1,\dots,g_r\).  Each \(g_i\) is a finite linear combination of finitely
many of the original \(f_\lambda\).  Collect all original polynomials that occur in these
expressions; call them \(f_{\lambda_1},\dots,f_{\lambda_N}\).  They still generate \(J\), so
\[
V_X(f_{\lambda_1},\dots,f_{\lambda_N})=V_X(J)=\varnothing.
\]
Taking complements gives
\[
X=D_X(f_{\lambda_1})\cup\cdots\cup D_X(f_{\lambda_N}).
\]
Thus the refined cover has a finite subcover, and therefore so did the original cover.

\paragraph{What happened mathematically.}
Topological compactness-like behavior comes from the Noetherian nature of polynomial rings.
No metric or boundedness argument is involved.

\paragraph{Extensions.}
Use the same method to show every open subset of a Noetherian topological space is
quasi-compact once Noetherianity is established.

\paragraph{Provenance.}
New canonical problem; it anticipates scheme-theoretic quasi-compactness while using only
VI/02 tools and Hilbert's basis theorem.
