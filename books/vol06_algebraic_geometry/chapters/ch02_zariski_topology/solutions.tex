\paragraph{Exercise \ref{ex:vi02-topology-axioms}.}
The whole space is \(V((0))\) and the empty set is \(V((1))\).  For any family
\(\{I_\lambda\}\),
\[
\bigcap_\lambda V(I_\lambda)
=
V\!\left(\sum_\lambda I_\lambda\right),
\]
so arbitrary intersections are closed.  For two ideals,
\[
V(I)\cup V(J)=V(IJ),
\]
so finite unions are closed; induction gives the result for any finite family.

\paragraph{Exercise \ref{ex:vi02-relative-closed}.}
If \(Y\) is closed in \(X\), then
\[
Y=X\cap Z
\]
for some ambient closed set \(Z=V(J)\).  Therefore
\[
Y=X\cap V(J)=V_X(J).
\]
Conversely every \(V_X(J)\) has this form, hence is closed in \(X\).

\paragraph{Exercise \ref{ex:vi02-closure}.}
Every polynomial in \(I(Y)\) vanishes on \(Y\), so
\[
Y\subseteq V(I(Y)).
\]
If \(Y\subseteq V(J)\), then every polynomial in \(J\) vanishes on \(Y\), hence
\[
J\subseteq I(Y).
\]
Order reversal gives
\[
V(I(Y))\subseteq V(J).
\]
Thus \(V(I(Y))\) is the smallest closed set containing \(Y\).

\paragraph{Exercise \ref{ex:vi02-principal-intersection}.}
For \(x\in X\),
\[
x\in D_X(f)\cap D_X(g)
\]
if and only if \(f(x)\neq0\) and \(g(x)\neq0\), if and only if
\[
f(x)g(x)\neq0.
\]
Hence
\[
D_X(f)\cap D_X(g)=D_X(fg).
\]
Inductively,
\[
\bigcap_{i=1}^rD_X(f_i)=D_X(f_1\cdots f_r).
\]

\paragraph{Exercise \ref{ex:vi02-principal-basis}.}
Let \(U\subseteq X\) be open and \(x\in U\).  Write
\[
X\setminus U=V_X(S).
\]
Since \(x\notin V_X(S)\), choose \(f\in S\) with \(f(x)\neq0\).  Then
\[
x\in D_X(f).
\]
If \(y\in D_X(f)\), then \(f(y)\neq0\), so \(y\notin V_X(S)\); thus
\[
D_X(f)\subseteq U.
\]

\paragraph{Exercise \ref{ex:vi02-points-closed}.}
A point \(x=(x_1,\dots,x_n)\) belongs to
\[
V(x_1-a_1,\dots,x_n-a_n)
\]
exactly when each coordinate equals the corresponding \(a_i\).  Hence the zero set is
\(\{a\}\).  Finite unions of closed sets are closed.

\paragraph{Exercise \ref{ex:vi02-a1-cofinite}.}
If \(Y=V(I)\) is proper, then \(I\neq(0)\); otherwise \(Y=\mathbb A^1_k\).  Pick
\(0\neq f\in I\).  Then
\[
Y\subseteq V(f),
\]
and \(V(f)\) is finite because a nonzero one-variable polynomial has finitely many roots.

\paragraph{Exercise \ref{ex:vi02-a1-not-hausdorff}.}
Every nonempty open set has finite complement.  If \(U,V\) are nonempty open sets, then
\[
k\setminus(U\cap V)=(k\setminus U)\cup(k\setminus V)
\]
is finite.  Since \(k\) is infinite, \(U\cap V\neq\varnothing\).  Thus distinct points
cannot be separated by disjoint open neighborhoods.

\paragraph{Exercise \ref{ex:vi02-infinite-dense}.}
If an infinite \(Y\subseteq\mathbb A^1_k\) had proper closure, that closure would be a proper
closed subset and therefore finite, contradicting \(Y\subseteq\overline Y\).

\paragraph{Exercise \ref{ex:vi02-finite-field-discrete}.}
Every point is Zariski closed.  Since \(k^n\) is finite, every subset is a finite union of
singletons, hence closed.  Therefore every subset is also open.

\paragraph{Exercise \ref{ex:vi02-relative-parabola}.}
On \(X\), \(x=0\) gives \(y=0\), so
\[
V_X(x)=\{(0,0)\},
\qquad
D_X(x)=X\setminus\{(0,0)\}.
\]
Similarly,
\[
V_X(x-1)=\{(1,1)\},
\qquad
D_X(x-1)=X\setminus\{(1,1)\}.
\]

\paragraph{Exercise \ref{ex:vi02-euclidean-coarser}.}
Every polynomial function is Euclidean continuous, so each \(V(f)\) is Euclidean closed.
Arbitrary intersections of such sets are Euclidean closed, hence every Zariski closed set is
Euclidean closed.  In \(\mathbb R\), for example,
\[
\mathbb Z
\]
is Euclidean closed but is not Zariski closed, because proper Zariski closed subsets of the
affine line are finite.

\paragraph{Exercise \ref{ex:vi02-density-criterion}.}
By the closure formula,
\[
\overline Y=V(I(Y)).
\]
Thus \(Y\) is dense exactly when \(V(I(Y))=\mathbb A^n_k\).  Over an infinite field,
\(I(\mathbb A^n_k)=(0)\), so this is equivalent to \(I(Y)=(0)\).

\paragraph{Exercise \ref{ex:vi02-grid-dense}.}
Suppose \(f(x,y)\) vanishes on \(A\times B\).  Write
\[
f(x,y)=\sum_{j=0}^m c_j(x)y^j.
\]
Fix \(a\in A\).  Then the one-variable polynomial \(f(a,y)\) vanishes on the infinite set
\(B\), so it is zero.  Hence
\[
c_j(a)=0
\]
for every \(j\) and every \(a\in A\).  Since \(A\) is infinite, each \(c_j\) is the zero
polynomial.  Thus \(f=0\), so \(I(A\times B)=(0)\), proving density.

\paragraph{Exercise \ref{ex:vi02-union-principal}.}
By De Morgan,
\[
D_X(f)\cup D_X(g)
=
X\setminus\bigl(V_X(f)\cap V_X(g)\bigr)
=
X\setminus V_X(f,g).
\]
The right side is the complement of a simultaneous zero set of two equations.  Nothing in
this identity alone produces a single polynomial whose nonvanishing is equivalent to
``\(f\neq0\) or \(g\neq0\)'' over every field and every \(X\).

\paragraph{Exercise \ref{ex:vi02-challenge-graph-density}.}
The graph satisfies \(y-p(x)=0\), so
\[
\Gamma_p\subseteq V(y-p(x)).
\]
Hence its closure is contained in that closed set.

Now let \(F(x,y)\) vanish on all of \(\Gamma_p\).  Divide \(F\), as a polynomial in \(y\),
by the monic polynomial \(y-p(x)\):
\[
F(x,y)=Q(x,y)(y-p(x))+R(x),
\]
where the remainder is independent of \(y\).  Evaluating at \(y=p(x)\) gives
\[
R(x)=F(x,p(x)).
\]
This vanishes for every \(x\in k\).  Since \(k\) is infinite, \(R=0\).  Thus every
polynomial vanishing on \(\Gamma_p\) is divisible by \(y-p(x)\), so
\[
I(\Gamma_p)=(y-p(x)).
\]
Therefore
\[
\overline{\Gamma_p}^{\,\mathrm{Zar}}
=
V(I(\Gamma_p))
=
V(y-p(x)).
\]
