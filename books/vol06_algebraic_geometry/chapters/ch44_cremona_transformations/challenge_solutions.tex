% VI44-DETAILED-CHALLENGE-01
\subsection*{Challenge VI.44.1}
\begin{solution}
A primitive quadratic birational map has a zero-dimensional base scheme of total multiplicity constrained by the homaloidal equalities.  With three distinct proper noncollinear simple base points, projective changes reduce the map to the standard net \(\langle xy,xz,yz\rangle\).  When points collide, the limiting base scheme retains tangent-direction data: one obtains infinitely near base points rather than merely fewer ordinary points.  Collinear proper points may force fixed components and destroy the standard net.  A correct classification therefore must record the cluster of proper and infinitely near points, which is precisely what blow-ups in VI/45 make geometric.
\end{solution}

% VI44-DETAILED-CHALLENGE-02
\subsection*{Challenge VI.44.2}
\begin{solution}
Represent the current birational map by the pullback of a general line.  Projective automorphisms merely change coordinates.  Each standard quadratic step replaces the numerical class \(dH-\sum m_iE_i\) according to the base-point multiplicities; exceptional curves sent into future base points create common factors and reduce degree.  Algorithmically, update the degree/multiplicity vector, remove fixed exceptional components, and read off the new \(H\)-coefficient.  Direct coordinate substitution followed by gcd cancellation gives the same number, with each canceled factor corresponding to one fixed/exceptional component.
\end{solution}

% VI44-DETAILED-CHALLENGE-03
\subsection*{Challenge VI.44.3}
\begin{solution}
For a cubic \(E\), the transformed degree is \(6-m_1-m_2-m_3\).  With no base points on \(E\), the image is a singular sextic; with one simple point it is a quintic; with two, a quartic; with three, another cubic.  In every noncontracted case the restriction is birational, so the normalization has genus one.  Whenever the plane degree exceeds three, singularities must absorb the difference between the plane arithmetic genus and one.  With three suitable simple points, the cubic model changes while remaining a cubic, linking Cremona transformations to alternate plane models of the same genus-one curve.
\end{solution}

% VI44-DETAILED-CHALLENGE-04
\subsection*{Challenge VI.44.4}
\begin{solution}
After blowing up the three base points, predict
\[
H\mapsto2H-E_1-E_2-E_3.
\]
Because the coordinate line through \(p_2,p_3\) is contracted to \(p_1\), the inverse image/action on the corresponding exceptional symbol is
\[
E_1\mapsto H-E_2-E_3,
\]
and cyclically.  Applying these rules twice returns each generator, so the transformation is an involution.  Using \(H^2=1\), \(H\cdot E_i=0\), \(E_i^2=-1\), \(E_i\cdot E_j=0\) for \(i\neq j\), a direct calculation shows the quadratic intersection form is preserved.  VI/45 will justify these formal intersection rules geometrically.
\end{solution}

% VI44-DETAILED-CHALLENGE-05
\subsection*{Challenge VI.44.5}
\begin{solution}
Near \(p_1\), use \(u=y/x,v=z/x\) and replace the origin in the \((u,v)\)-plane by direction charts \(v=ut\) and \(u=vs\).  In the first chart,
\[
[uv:v:u]=[u^2t:ut:u]=[ut:t:1],
\]
which extends regularly to \(u=0\) with value \([0:t:1]\).  The second chart handles the missing vertical direction.  Cyclic copies resolve \(p_2,p_3\).  The exceptional coordinate \(u=0\) (or its analogues) parametrizes the projective line of tangent directions.  This chart calculation is exactly the local model of the blow-up and shows why the formerly indeterminate map becomes regular after the replacement.
\end{solution}
