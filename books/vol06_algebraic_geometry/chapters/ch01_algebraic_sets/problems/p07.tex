\subsection*{Problem VI.01.P7 --- An infinite system has a finite subsystem}
\label{prob:vi01-p7}

\paragraph{Problem.}
Assume Hilbert's basis theorem.  Let
\[
S\subseteq k[x_1,\dots,x_n]
\]
be an arbitrary, possibly infinite, family of equations.  Prove that there is a finite
subset \(S_0\subseteq S\) such that
\[
(S_0)=(S)
\]
and therefore
\[
V(S_0)=V(S).
\]
Explain why finite generation of \((S)\) alone does not immediately say the chosen
generators belong to \(S\), and how to repair that point.

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
The definition of an algebraic set permits infinitely many equations, but affine polynomial
rings are Noetherian.  This problem makes the finite-reduction argument completely precise.

\paragraph{Useful ideas before starting.}
Choose finite generators \(g_1,\dots,g_m\) for \((S)\).  Each \(g_i\) is itself a finite
linear combination of elements of \(S\).

\paragraph{Guided hints.}
\textbf{Hint 1.} Write each \(g_i\) as
\[
g_i=\sum_{j=1}^{r_i}h_{ij}s_{ij},
\qquad s_{ij}\in S.
\]

\textbf{Hint 2.} Let \(S_0\) be the finite union of all \(s_{ij}\) that occur.

\paragraph{Solution.}
Hilbert's basis theorem gives
\[
(S)=(g_1,\dots,g_m)
\]
for finitely many \(g_i\in(S)\).  The \(g_i\) need not themselves be elements of the
original family \(S\).  However, by definition of the generated ideal, each has an
expression
\[
g_i=\sum_{j=1}^{r_i}h_{ij}s_{ij}
\]
with \(s_{ij}\in S\).  Let \(S_0\) be the finite set of all source elements \(s_{ij}\)
appearing in all these expressions.  Then every \(g_i\in(S_0)\), so
\[
(S)=(g_1,\dots,g_m)\subseteq(S_0).
\]
The reverse inclusion follows from \(S_0\subseteq S\).  Therefore
\[
(S_0)=(S),
\]
and hence their zero loci agree.

\paragraph{What happened mathematically.}
Noetherianity does more than say the ideal has some finite basis: the finite basis itself
uses only finitely many of the original equations, so a genuinely finite subsystem already
cuts out the same geometry.

\paragraph{Extensions.}
\begin{enumerate}
\item Give an explicit infinite family where many equations are redundant.
\item Ask how one can compute a useful finite generating set algorithmically; this points to
      Groebner bases.
\item Compare this finite-equation property with non-Noetherian polynomial-like rings.
\end{enumerate}

New canonical problem sharpening the chapter's Hilbert-basis-theorem consequence.
