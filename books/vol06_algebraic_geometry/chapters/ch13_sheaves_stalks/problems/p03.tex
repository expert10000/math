\begin{problem}[The constant presheaf versus the constant sheaf]
Let $A$ be a nonzero abelian group. Compare the naive constant presheaf $A^{pre}$ with the sheaf $\underline A$ of locally constant $A$-valued functions. Prove that $A^{pre}$ fails gluing on a disconnected open set, compute $\underline A(U)$ from the connected components of $U$, and determine when the canonical map $A^{pre}(U)\to\underline A(U)$ is an isomorphism.
\end{problem}

\paragraph{Why this problem matters.}
This is the first important example where sheafification changes global sections but not the intended local values.

\paragraph{Useful ideas before starting.}
A locally constant function is constant on each connected component. A single element of $A$ forces the same value everywhere.

\paragraph{Guided hints.}
If $U=\coprod U_\alpha$, identify a locally constant map with the tuple of its componentwise values.

\ifdefined\FullProblemDossiers
\begin{solution}
On a disconnected $U=U_1\sqcup U_2$, distinct $a,b\in A$ define compatible local sections of the naive constant presheaf but cannot come from one global element, so gluing fails. For the constant sheaf, a locally constant function is constant on every connected component and every choice of componentwise constants is locally constant, hence
\[
\underline A(U)\cong\prod_{\alpha\in\pi_0(U)}A.
\]
The canonical map sends $a$ to the constant tuple $(a)_\alpha$. It is an isomorphism exactly when $U$ is empty (with the chosen zero convention) or has one connected component; more generally it is injective on nonempty $U$ and its image consists of constant tuples.
\end{solution}

\paragraph{What happened mathematically.}
Sheaves permit local choices that vary between disconnected components while remaining locally constant.

\paragraph{Extensions.}
Investigate the naive constant presheaf on irreducible spaces, where every two nonempty opens meet.
