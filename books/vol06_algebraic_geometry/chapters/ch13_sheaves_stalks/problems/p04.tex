\begin{problem}[Bounded continuous functions: a precise gluing failure]
On $X=\RR$, let $\mathcal B(U)$ be the bounded continuous real-valued functions. Prove that $\mathcal B$ is a presheaf and satisfies locality but not gluing. Determine exactly which part of the sheaf axiom fails in the standard cover $U_n=(-n,n)$.
\end{problem}

\paragraph{Why this problem matters.}
It separates restriction, locality, and gluing, showing that a genuinely global boundedness condition is not sheaf-local.

\paragraph{Useful ideas before starting.}
Restriction preserves boundedness. Equality is pointwise. Use the compatible functions $x\mapsto x$.

\paragraph{Guided hints.}
The only candidate global gluing is forced pointwise, so there is no alternative bounded section that could work.

\ifdefined\FullProblemDossiers
\begin{solution}
Restriction of a bounded continuous function remains bounded and continuous, so the presheaf axioms hold. If two bounded continuous functions agree on a cover, they agree pointwise, so locality holds. On $U_n=(-n,n)$ let $s_n(x)=x$. Each $s_n$ is bounded and the family is compatible. Any gluing $s$ must satisfy $s(x)=x$ for every $x$, because every point lies in some $U_n$. This function is unbounded on $\RR$, so $s\notin\mathcal B(\RR)$. Thus existence in the gluing axiom fails, while uniqueness would hold if a gluing existed.
\end{solution}

\paragraph{What happened mathematically.}
A local property survives gluing; a global uniform bound need not.

\paragraph{Extensions.}
Analyze bounded holomorphic functions and functions with compact support under the same lens.
