\begin{problem}[Support via germs]
For a sheaf of abelian groups $\mathcal F$ and $s\in\mathcal F(U)$, prove that
\[
Z_g(s):=\{x\in U:s_x=0\}
\]
is open. Define $\operatorname{supp}(s)=U\setminus Z_g(s)=\{x:s_x\neq0\}$ and prove that this set is closed.  For ordinary function sheaves, relate it to the closure of the pointwise nonvanishing set. Compute supports for standard continuous bump functions and for a skyscraper section.
\end{problem}

\paragraph{Why this problem matters.}
Support is fundamentally a stalkwise notion and is crucial later for extension, cohomology, and distributions.

\paragraph{Useful ideas before starting.}
A zero germ is represented by an actual zero section on some neighborhood.

\paragraph{Guided hints.}
For a skyscraper section, use the arbitrary-space stalk computation before imposing $T_1$.

\ifdefined\FullProblemDossiers
\begin{solution}
If $s_x=0$, equality of germs means there exists a neighborhood $V_x\subseteq U$ on which $s|_{V_x}=0$. Every point of $V_x$ also has zero germ, so $Z_g(s)$ is open. Thus the nonzero-germ locus is closed for every sheaf of abelian groups, and it is natural to define it as the support.  For an ordinary function sheaf, a boundary point of the pointwise nonvanishing locus still has nonzero germ unless the function vanishes on a whole neighborhood, so this germ-theoretic set equals the closure of the pointwise nonvanishing set. For a bump function supported in $[-1,1]$, the support is $[-1,1]$. For a nonzero skyscraper section on a $T_1$ space, the nonzero-germ locus is $\{x\}$ and the support is $\{x\}$. On non-$T_1$ spaces it may include points whose every neighborhood contains $x$.
\end{solution}

\paragraph{What happened mathematically.}
A section vanishes near a point exactly when its germ is zero; support packages the failure of this local vanishing.

\paragraph{Extensions.}
Define the support of an entire sheaf as the set of points with nonzero stalk.
