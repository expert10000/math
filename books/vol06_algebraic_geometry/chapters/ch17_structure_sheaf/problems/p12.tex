\begin{problem}[Global functions on the punctured affine plane]\label{prob:vi17-p12}
Let $A=k[x,y]$ and $U=D(x)\cup D(y)$.  Prove $\OO_X(U)\cong A$.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
This is a first striking example where deleting a codimension-two closed point creates no new global regular functions.

\paragraph{Useful ideas.}
Use the equalizer $A_x\times_{A_{xy}}A_y$ and view both localizations inside $k(x,y)$.

\paragraph{Guided hints.}
\begin{enumerate}
\item A compatible pair determines one rational function lying in both $A_x$ and $A_y$.
\item Show $A_x\cap A_y=A$ inside $k(x,y)$ using unique factorization.
\end{enumerate}

\begin{solution}
Compatibility identifies the two localized elements with one rational function $r\in k(x,y)$ satisfying $r\in A_x\cap A_y$.  Write $r=p/x^m=q/y^n$ with $p,q\in A$.  Then $y^np=x^mq$.  Since $x$ and $y$ are relatively prime primes in the UFD $k[x,y]$, $x^m$ divides $p$ and $y^n$ divides $q$.  Thus $r\in A$.  The reverse inclusion is obvious, so $A_x\cap A_y=A$, and hence $\OO_X(U)=A$.
\end{solution}

\paragraph{What happened mathematically.}
The sheaf can have the same global section ring on a proper open subset; global sections alone do not determine the open set.

\paragraph{Extensions.}
Investigate $\mathbb A^n\setminus\{0\}$ for $n\ge2$ and normal domains.
