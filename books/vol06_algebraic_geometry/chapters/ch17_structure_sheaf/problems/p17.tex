\begin{problem}[Detecting zero germs algebraically]\label{prob:vi17-p17}
For $a\in A$ and $\mfp\in\Spec A$, prove
\[a/1=0\text{ in }\OO_{X,\mfp}\iff\exists s\notin\mfp\text{ with }sa=0.\]
Give a nontrivial example in $A=k[x,y]/(xy)$.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
This is the correct local vanishing test in rings with zero divisors.

\paragraph{Useful ideas.}
Use the zero criterion in a localization; for the example exploit the relation $xy=0$.

\paragraph{Guided hints.}
\begin{enumerate}
\item Apply the localization zero criterion directly.
\item At the prime $(x)$, the element $y$ is outside the prime.
\end{enumerate}

\begin{solution}
By the stalk theorem, the germ is $a/1$ in $A_{\mfp}$.  A fraction $a/1$ is zero in a localization iff some element of the multiplicative set annihilates $a$; here the multiplicative set is $A\setminus\mfp$.  Thus the stated condition follows.  For $A=k[x,y]/(xy)$ and $\mfp=(x)$, one has $y\notin\mfp$ and $yx=0$, so the nonzero global element $x$ has zero germ at $\mfp$.
\end{solution}

\paragraph{What happened mathematically.}
Local vanishing is sensitive to annihilators that become units after localization.

\paragraph{Extensions.}
Describe the set of primes where a fixed global section has zero germ in terms of its annihilator.
