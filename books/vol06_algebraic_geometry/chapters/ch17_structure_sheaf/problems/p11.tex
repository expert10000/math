\begin{problem}[The generic stalk is the function field]\label{prob:vi17-p11}
Let $A$ be a domain and $X=\Spec A$.  Prove $\OO_{X,(0)}\cong\Frac(A)$ and explain why every nonempty principal open contains $(0)$.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
The generic point packages rational functions as local regular functions at the densest point.

\paragraph{Useful ideas.}
Use that the complement of $(0)$ is the set of nonzero elements.

\paragraph{Guided hints.}
\begin{enumerate}
\item Compute $A_{(0)}$.
\item $D(f)$ contains $(0)$ exactly when $f
e0$.
\end{enumerate}

% VI17_FULL_SOLUTION_REFINED
% VI17_FULL_SOLUTION_REFINED
\begin{solution}
Because $A$ is a domain, the zero ideal is prime.  Its complement is precisely the multiplicative set of nonzero elements of $A$.  Therefore
\[
A_{(0)}=(A\setminus\{0\})^{-1}A=\Frac(A).
\]
By the stalk theorem,
\[
\OO_{X,(0)}\cong A_{(0)}=\Frac(A).
\]

Now consider a principal open $D(f)$.  The generic point $(0)$ lies in $D(f)$ exactly when $f\notin(0)$, i.e. when $f\neq0$.  If $f=0$, then $D(f)=\varnothing$; if $f\neq0$, then $(0)\in D(f)$ and the open is nonempty.  Hence every nonempty principal open contains the generic point.

Since principal opens form a basis, this also implies that the generic point lies in every nonempty open subset of $\Spec A$, explaining its density.  The function field is therefore literally the local ring of functions at the dense generic point.
\end{solution}



\paragraph{What happened mathematically.}
The function field is not added externally; it is already a stalk of the structure sheaf.

\paragraph{Extensions.}
For a reduced reducible ring, compute the local rings at the minimal primes and interpret them as componentwise function fields when they are fields.
