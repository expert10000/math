\subsection*{VI.23.P17: Points are not merely compatible pairs}
\begin{problem}\label{prob:vi23-p17}
Explain why the underlying set of $X\times_SY$ cannot in general be identified with
$|X|\times_{|S|}|Y|$.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
This warns against one of the most common false intuitions about products of schemes.

\paragraph{Useful ideas before starting.}
Translate the requested statement into compatible maps from an arbitrary test scheme, and use uniqueness before choosing coordinates.

\paragraph{Guided hints.}
\begin{enumerate}
\item There is always a map from product points to compatible pairs.
\item Describe the residual algebra over a fixed pair.
\item Use $\mathbb C\otimes_{\mathbb R}\mathbb C$ for an explicit example.
\end{enumerate}

\begin{solution}
Every product point $z$ maps to a compatible pair $(x,y)$ with common image $s$ in $S$, so
there is a natural map
\[
|X\times_SY|\longrightarrow |X|\times_{|S|}|Y|.
\]
It need not be injective.  Fix a compatible pair $(x,y)$.  The residue maps induced by
$x\to s$ and $y\to s$ make $\kappa(x)$ and $\kappa(y)$ into $\kappa(s)$-algebras.  The points
of the fiber product lying over the pair are naturally controlled by
\[
\Spec\bigl(\kappa(x)\otimes_{\kappa(s)}\kappa(y)\bigr).
\]
If this ring has several primes, the single pair $(x,y)$ lifts to several scheme points.

For a concrete example take $S=\Spec\mathbb R$ and
$X=Y=\Spec\mathbb C$.  Each of $S,X,Y$ has one point, so the set-theoretic fiber product has
one element.  But
\[
\mathbb C\otimes_{\mathbb R}\mathbb C\cong\mathbb C\times\mathbb C,
\]
whose spectrum has two points.  Hence $X\times_SY$ has two points.

The issue is not an exotic topological artifact: it records the distinct ways the two residue
fields can meet over the residue field of the base.
\end{solution}

\paragraph{What happened mathematically.}
A geometric assertion was reduced to a representability statement, so the canonical map was forced by universality.

\paragraph{Extensions.}
Repeat the argument after restricting to affine opens and compare with the tensor-product formula.
