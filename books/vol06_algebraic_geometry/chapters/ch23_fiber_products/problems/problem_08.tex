\subsection*{VI.23.P8: Associativity}
\begin{problem}\label{prob:vi23-p08}
For $X,Y,Z\to S$, prove
\[
(X\times_SY)\times_SZ\cong X\times_S(Y\times_SZ).
\]
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
Associativity lets us write multiple fiber products without treating parenthesization as new geometric data.

\paragraph{Useful ideas before starting.}
Translate the requested statement into compatible maps from an arbitrary test scheme, and use uniqueness before choosing coordinates.

\paragraph{Guided hints.}
\begin{enumerate}
\item Describe a test map to the left bracketing.
\item Expand the inner fiber-product datum.
\item Repeat for the right bracketing and compare.
\end{enumerate}

\begin{solution}
Let $P=(X\times_SY)\times_SZ$.  A map $Q\to P$ consists of a map
$Q\to X\times_SY$ and a map $Q\to Z$ with equal composites to $S$.  Expanding the first map,
the datum is exactly a triple
\[
a:Q\to X,\qquad b:Q\to Y,\qquad c:Q\to Z
\]
satisfying
\[
f_Xa=f_Yb=f_Zc.
\]
The same calculation for $P'=X\times_S(Y\times_SZ)$ gives the identical set of triples.

The identifications are natural in $Q$, hence $P$ and $P'$ represent the same functor.  Therefore
there is a unique canonical isomorphism $P\cong P'$ compatible with all three projections.
The inverse is obtained from the same triple in the other direction, and uniqueness makes the
two composites identities.
\end{solution}

\paragraph{What happened mathematically.}
A geometric assertion was reduced to a representability statement, so the canonical map was forced by universality.

\paragraph{Extensions.}
Repeat the argument after restricting to affine opens and compare with the tensor-product formula.
