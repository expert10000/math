\subsection*{VI.23.P20: Boundary preview: fibers without computing them}
\begin{problem}\label{prob:vi23-p20}
Let $X\to S$ and $s\in S$. Explain formally why
$X\times_S\Spec\kappa(s)$ is the correct object to call the fiber over $s$, without performing
any detailed fiber computation.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
This problem fixes the correct definition of a scheme-theoretic fiber while respecting the corpus boundary with VI/25.

\paragraph{Useful ideas before starting.}
Translate the requested statement into compatible maps from an arbitrary test scheme, and use uniqueness before choosing coordinates.

\paragraph{Guided hints.}
\begin{enumerate}
\item Use the canonical point morphism from VI/21.
\item Write the fiber-product universal property.
\item Interpret the commutativity condition as ``the map to $S$ factors through $s$''.
\end{enumerate}

\begin{solution}
VI/21 attaches to $s\in S$ the canonical point morphism
\[
i_s:\Spec\kappa(s)\to S.
\]
Form the pullback
\[
X_s:=X\times_S\Spec\kappa(s).
\]
For a test scheme $T$, a morphism $T\to X_s$ is equivalent to a pair
\[
a:T\to X,\qquad b:T\to\Spec\kappa(s)
\]
such that the composite $T\xrightarrow aX\to S$ equals $i_s b$.  In other words, $X_s$
universally parametrizes maps to $X$ whose map to the base factors through the selected
scheme-theoretic point $s$.

That is exactly the categorical meaning of ``lying over $s$''.  The residue field is essential:
using only the one-point topological space would discard the scalar structure that controls the
actual fiber.

This establishes the correct object formally.  We deliberately stop here.  VI/25 is assigned the
detailed affine formula, point analysis, geometric fibers, and examples of how fiber geometry can
change.
\end{solution}

\paragraph{What happened mathematically.}
A geometric assertion was reduced to a representability statement, so the canonical map was forced by universality.

\paragraph{Extensions.}
Repeat the argument after restricting to affine opens and compare with the tensor-product formula.
