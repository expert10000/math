\begin{problem}[A skyscraper-type presheaf]
Fix $x\in X$ and an abelian group $A$.  Study the presheaf $\mathcal K_x(U)=A$ if $x\in U$ and $0$ otherwise.  Determine all endomorphisms of $\mathcal K_x$.
\end{problem}

\paragraph{Why this problem matters.}
This is a concrete local-data object and precursor of skyscraper sheaves.

\paragraph{Useful ideas before starting.}
Every nonzero value occurs precisely on opens containing $x$.

\paragraph{Guided hints.}
Every nonzero value occurs precisely on opens containing $x$.

\begin{solution}
The restriction maps are forced: identity between opens containing $x$ and zero whenever the target omits $x$.  A morphism $\mathcal K_x(A)\to\mathcal K_x(A)$ is determined by one homomorphism $A\to A$, used on every open containing $x$; naturality forces the same homomorphism everywhere.  Hence $\operatorname{End}(\mathcal K_x)\cong\operatorname{End}(A)$.
\end{solution}

\paragraph{What happened mathematically.}
A presheaf can concentrate all algebraic data near one point.

\paragraph{Extensions.}
Analyze maps between $\mathcal K_x(A)$ and $\mathcal K_y(B)$ for $x\ne y$.

\paragraph{Provenance.}
New canonical synthesis problem.
