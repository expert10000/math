\begin{problem}[Bounded functions and infinite gluing]
Let $\mathcal B(U)$ be bounded continuous functions $U\to\RR$.  Prove $\mathcal B$ is a presheaf.  Then prove that on $\RR$ it fails the sheaf gluing axiom using the cover $(-n,n)$.
\end{problem}

\paragraph{Why this problem matters.}
This isolates the difference between restriction-stable conditions and globally bounded conditions.

\paragraph{Useful ideas before starting.}
Use the compatible family $s_n(x)=x$.

\paragraph{Guided hints.}
Use the compatible family $s_n(x)=x$.

\begin{solution}
Restriction preserves continuity and boundedness, so $\mathcal B$ is a presheaf.  The functions $s_n(x)=x$ are bounded on $(-n,n)$ and agree on overlaps.  Any global glue must equal $x$ everywhere because the opens cover $\RR$.  That function is unbounded, hence is not in $\mathcal B(\RR)$.  Thus gluing fails.
\end{solution}

\paragraph{What happened mathematically.}
A property can survive every restriction yet fail to survive gluing across an infinite cover.

\paragraph{Extensions.}
Find a similar example using functions with a global norm bound.

\paragraph{Provenance.}
New canonical synthesis problem.
