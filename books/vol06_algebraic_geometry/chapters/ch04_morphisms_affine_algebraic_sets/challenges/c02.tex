\subsection*{Challenge VI.04.C2 --- Power maps have no polynomial section}
\label{chal:vi04-c2}
\paragraph{Challenge.}
Let \(d>1\) and \(p_d:\mathbb A^1\to\mathbb A^1\), \(t\mapsto t^d\).  Show that there is
no morphism \(s:\mathbb A^1\to\mathbb A^1\) with \(p_d\circ s=\operatorname{id}\), and no
morphism \(r\) with \(r\circ p_d=\operatorname{id}\).
\ifdefined\FullProblemDossiers
\paragraph{Guided hints.}  For a right inverse write \(s(t)=q(t)\) and compare degrees in
\(q(t)^d=t\).  For a left inverse use pullbacks: the image of \(p_d^*\) is \(k[t^d]\).
\paragraph{Solution.}
If \(p_d\circ s=\operatorname{id}\), then \(q(t)^d=t\), impossible because degrees give
\(d\deg q=1\).  If \(r\circ p_d=\operatorname{id}\), contravariance gives
\(p_d^*\circ r^*=\operatorname{id}_{k[t]}\), so \(p_d^*\) would be surjective; but its
image is \(k[t^d]\subsetneq k[t]\).
\paragraph{Extension.}  Compare with the power map on \(\mathbb G_m\), where negative
exponents are allowed in coordinate functions but a section still exists only for
\(d=\pm1\).
\fi
