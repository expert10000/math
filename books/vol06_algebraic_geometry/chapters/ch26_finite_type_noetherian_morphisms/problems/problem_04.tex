\begin{problem}[Finite type is locally finite type plus quasi-compact]\label{prob:vi26-p04}
Prove Theorem~\ref{thm:vi26-ft-lft-qc} from the affine-cover definition of finite type.
\par\smallskip\noindent\textit{Provenance.} Canonical VI/26 dossier developed from the audited AG5/AG6 finiteness theory streams; no additional numbered legacy problem is claimed.
\end{problem}
\begin{solution}
If $f$ is finite type, the defining finite affine covers over affine target charts show both local finite type and quasi-compactness.  Conversely, suppose $f$ is locally finite type and quasi-compact.  Over an affine $V=\Spec B$, local finite type gives an affine cover of $f^{-1}(V)$ by finite-type $B$-algebras.  Since $f^{-1}(V)$ is quasi-compact, finitely many of those affine opens suffice.  This is exactly the finite-type condition.
\end{solution}
