\begin{problem}[Finite type is locally finite type plus quasi-compact]\label{prob:vi26-p04}
Prove Theorem~\ref{thm:vi26-ft-lft-qc} from the affine-cover definition of finite type.
\par\smallskip\noindent\textit{Provenance.} Canonical VI/26 dossier developed from the audited AG5/AG6 finiteness theory streams; no additional numbered legacy problem is claimed.
\end{problem}

\ifdefined\FullProblemDossiers
\begin{solution}
Suppose first that \(f:X\to Y\) is finite type.  By definition, over every affine
\(V=\Spec A\subseteq Y\), the inverse image \(f^{-1}(V)\) has a finite affine cover
\[
f^{-1}(V)=U_1\cup\cdots\cup U_r
\]
with each coordinate ring finite type over \(A\).  Forgetting finiteness of the cover shows local
finite type.  Since each \(U_i\) is quasi-compact and there are only finitely many of them,
\(f^{-1}(V)\) is quasi-compact.  Therefore \(f\) is quasi-compact.

Conversely, assume \(f\) is locally finite type and quasi-compact.  For an affine
\(V=\Spec A\subseteq Y\), local finite type supplies an affine open cover of \(f^{-1}(V)\) by
spectra of finitely generated \(A\)-algebras.  Quasi-compactness of \(f\) implies
\(f^{-1}(V)\) is quasi-compact, so finitely many of those affine opens already cover.  This is
exactly the affine-cover definition of a finite-type morphism.
\end{solution}
\fi
