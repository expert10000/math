\begin{problem}[Finite type is local on the target]\label{prob:vi26-p18}
Suppose \(Y=\bigcup_iV_i\) is an open cover and each restricted morphism \(f^{-1}(V_i)\to V_i\) is finite type.  Show \(f\) is finite type.
\par\smallskip\noindent\textit{Provenance.} Canonical VI/26 dossier developed from the audited AG5/AG6 finiteness theory streams; no additional numbered legacy problem is claimed.
\end{problem}

\ifdefined\FullProblemDossiers
\begin{solution}
Local finite type is local on the target, so the restrictions immediately imply that \(f\) is
locally finite type.  We must prove \(f\) quasi-compact.

It suffices to show that \(f^{-1}(W)\) is quasi-compact for every affine open
\(W=\Spec A\subseteq Y\).  The opens \(W\cap V_i\) cover the quasi-compact affine scheme \(W\).
Using the distinguished-open basis of \(W\), choose finitely many principal opens
\[
D(g_1),\ldots,D(g_r)
\]
covering \(W\), with each \(D(g_j)\) contained in some \(V_{i(j)}\).  The restricted morphism over
\(V_{i(j)}\) is finite type, hence quasi-compact.  Since each \(D(g_j)\) is quasi-compact,
\[
f^{-1}(D(g_j))
\]
is quasi-compact.  Therefore
\[
f^{-1}(W)=\bigcup_{j=1}^r f^{-1}(D(g_j))
\]
is a finite union of quasi-compact opens, hence quasi-compact.  Thus \(f\) is quasi-compact and
locally finite type, so it is finite type.
\end{solution}
\fi
