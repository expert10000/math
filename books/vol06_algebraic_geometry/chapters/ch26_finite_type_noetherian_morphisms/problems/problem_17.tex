\begin{problem}[Localization is finite type]\label{prob:vi26-p17}
Show $A\to A_f$ is a finite-type ring map and interpret geometrically.
\par\smallskip\noindent\textit{Provenance.} Canonical VI/26 dossier developed from the audited AG5/AG6 finiteness theory streams; no additional numbered legacy problem is claimed.
\end{problem}
\begin{solution}
There is an isomorphism $A_f\cong A[t]/(ft-1)$, so one generator suffices.  Geometrically, $D(f)=\Spec A_f\hookrightarrow\Spec A$ is an open immersion that is finite type.
\end{solution}
