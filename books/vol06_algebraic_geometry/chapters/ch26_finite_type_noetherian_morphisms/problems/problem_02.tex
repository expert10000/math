\begin{problem}[Legacy AG6-P5 with AG5-P5 merged: locally finite type on every affine open]\label{prob:vi26-p02}
Prove that $f:X\to Y$ is locally of finite type if and only if for every affine open $V=\Spec B\subseteq Y$, the inverse image $f^{-1}(V)$ has an affine open cover $\Spec A_j$ with each $A_j$ finitely generated over $B$.
\par\smallskip\noindent\textit{Provenance.} Legacy AG6-P5; AG5-P5 is a duplicate/variant merged here, not a second canonical problem.
\end{problem}
\begin{solution}
Only the nontrivial direction needs proof.  Start from an affine cover $V_i=\Spec B_i$ witnessing local finite type.  Given $y\in V\cap V_i$, choose a common distinguished neighborhood $W=D(b)\subseteq V$ and $W=D(c)\subseteq V_i$.  If $U_{ij}=\Spec A_{ij}$ is a finite-type affine source chart over $V_i$, then $U_{ij}\cap f^{-1}(W)$ is the distinguished open $\Spec (A_{ij})_{\varphi(c)}$.  This localization is finite type over $(B_i)_c\cong B_b$, and $B_b\cong B[t]/(bt-1)$ is finite type over $B$.  Transitivity gives finite generation over $B$.  These common distinguished neighborhoods cover $V$, hence their inverse-image affine refinements cover $f^{-1}(V)$.
\end{solution}
