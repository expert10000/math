% VI26-DETAILED-PROBLEM-15
\begin{problem}[Fibers inherit finite type]\label{prob:vi26-p15}
Let \(f:X\to S\) be locally finite type.  Prove that every fiber \(X_s\) is locally finite type over \(\kappa(s)\); if \(f\) is finite type, prove \(X_s\) finite type.
\par\smallskip\noindent\textit{Provenance.} Canonical VI/26 dossier developed from the audited AG5/AG6 finiteness theory streams; no additional numbered legacy problem is claimed.
\end{problem}

\ifdefined\FullProblemDossiers
\begin{solution}
By VI/25,
\[
X_s=X\times_S\Spec\kappa(s).
\]
Thus the fiber is the base change of \(f\) along the point morphism
\(\Spec\kappa(s)\to S\).  Problem~8 therefore implies that \(X_s\to\Spec\kappa(s)\) is locally
finite type whenever \(f\) is locally finite type.  If \(f\) is finite type, Problem~9 gives the
stronger finite-type conclusion.

Affinely, if \(S=\Spec A\), \(X=\Spec B\), and \(s\leftrightarrow\mathfrak p\), then
\[
X_s=\Spec(B\otimes_A\kappa(\mathfrak p)).
\]
If \(B=A[b_1,\ldots,b_n]\), the fiber ring is generated over \(\kappa(\mathfrak p)\) by the images
\(b_i\otimes1\).  This gives the same result directly.
\end{solution}
\fi
