\begin{problem}[Base change of finite type]\label{prob:vi26-p09}
Prove that a base change of a finite-type morphism is finite type.
\par\smallskip\noindent\textit{Provenance.} Canonical VI/26 dossier developed from the audited AG5/AG6 finiteness theory streams; no additional numbered legacy problem is claimed.
\end{problem}
\begin{solution}
By Problem 8 the base change is locally finite type.  Quasi-compactness is stable under base change, so Theorem~\ref{thm:vi26-ft-lft-qc} applies.
\end{solution}
