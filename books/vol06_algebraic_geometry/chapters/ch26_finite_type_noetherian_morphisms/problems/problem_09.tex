\begin{problem}[Base change of finite type]\label{prob:vi26-p09}
Prove that a base change of a finite-type morphism is finite type.
\par\smallskip\noindent\textit{Provenance.} Canonical VI/26 dossier developed from the audited AG5/AG6 finiteness theory streams; no additional numbered legacy problem is claimed.
\end{problem}

\ifdefined\FullProblemDossiers
\begin{solution}
Use the same Cartesian square as in Problem~8.  Problem~8 proves that \(f'\) is locally finite type.

It remains to check quasi-compactness.  Quasi-compact morphisms are stable under base change.  One
can see this affine-locally: over an affine \(V=\Spec A\subseteq S\), a finite-type morphism has
a finite affine cover \(U_1,\ldots,U_r\) of \(f^{-1}(V)\).  After pulling back to an affine
\(V'=\Spec A'\subseteq S'\) lying over \(V\), the finitely many affines
\[
U_i\times_VV'
\]
cover \(f'^{-1}(V')\), so this inverse image is quasi-compact.  Refining \(S'\) by such affine opens
proves \(f'\) quasi-compact.  Hence \(f'\) is finite type.
\end{solution}
