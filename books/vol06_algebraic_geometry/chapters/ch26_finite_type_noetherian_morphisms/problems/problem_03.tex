\begin{problem}[Legacy AG6-P6e: the three finiteness counterexamples]\label{prob:vi26-p03}
Over a field $k$, verify: (a) $\Spec k[x_1,x_2,\ldots]$ is not Noetherian; (b) its structure morphism to $\Spec k$ is not locally of finite type; (c) $\coprod_{n\ge1}\Spec k\to\Spec k$ is locally of finite type but not of finite type.
\par\smallskip\noindent\textit{Provenance.} Preserves the finite-type/Noetherian subparts grouped in legacy row AG6-P6e.
\end{problem}
\begin{solution}
For (a), the chain $(x_1)\subsetneq(x_1,x_2)\subsetneq\cdots$ never stabilizes.  For (b), the coordinate ring needs infinitely many algebra generators; more strongly, every basic neighborhood of the generic point still contains infinitely many independent variables, so no finite-type affine neighborhood exists there.  For (c), each component $\Spec k$ is a finite-type affine chart, so the morphism is locally of finite type.  But the source is not quasi-compact: its components form an open cover with no finite subcover.  Hence the morphism is not finite type.
\end{solution}
