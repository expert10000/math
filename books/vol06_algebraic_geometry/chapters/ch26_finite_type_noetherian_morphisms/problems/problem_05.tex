\begin{problem}[Affine criterion for finite type]\label{prob:vi26-p05}
Let $A\to B$ be a ring map.  Show that $\Spec B\to\Spec A$ is finite type if $B$ is finitely generated as an $A$-algebra.
\par\smallskip\noindent\textit{Provenance.} Canonical VI/26 dossier developed from the audited AG5/AG6 finiteness theory streams; no additional numbered legacy problem is claimed.
\end{problem}
\begin{solution}
The source itself is one affine open, so local finite type is immediate from finite generation.  Affine schemes are quasi-compact, so the morphism is quasi-compact over the affine target.  Thus it is finite type.
\end{solution}
