% VI26 detailed exercise solutions -- VI/24-depth standard.

% VI26-DETAILED-EXERCISE-01
\paragraph{Solution 1.}
Let \(B=A[b_1,\ldots,b_n]\), and let \(q:B\twoheadrightarrow C\) be the quotient map.
Every element of \(B\) is an \(A\)-polynomial in the \(b_i\), so applying \(q\) shows that every
element of \(C\) is the same polynomial in \(\bar b_i=q(b_i)\).  Hence
\[
C=A[\bar b_1,\ldots,\bar b_n].
\]
Thus quotients preserve finite generation as algebras.  Geometrically, a closed subscheme of an
affine finite-type \(A\)-scheme is again finite type over \(\Spec A\).

% VI26-DETAILED-EXERCISE-02
\paragraph{Solution 2.}
Introduce one indeterminate \(t\) and define
\[
\Phi:A[t]\longrightarrow A_f,\qquad
a\longmapsto a/1,\quad t\longmapsto f^{-1}.
\]
The relation \(ft-1\) lies in the kernel, so \(\Phi\) factors through
\(A[t]/(ft-1)\).  Conversely, in \(A[t]/(ft-1)\) the class of \(f\) is invertible with inverse
the class of \(t\).  The universal property of localization therefore gives a map
\(A_f\to A[t]/(ft-1)\), and the two maps are inverse.  Hence
\[
A_f\cong A[t]/(ft-1),
\]
so \(A_f\) is generated by one element as an \(A\)-algebra.  Therefore
\(D(f)\to\Spec A\) is a finite-type open immersion.

% VI26-DETAILED-EXERCISE-03
\paragraph{Solution 3.}
Suppose
\[
B=A[b_1,\ldots,b_m],
\qquad
C=B[c_1,\ldots,c_n].
\]
An element of \(C\) is a polynomial in the \(c_j\) with coefficients in \(B\), and each such
coefficient is a polynomial in the \(b_i\) with coefficients in \(A\).  Substituting gives
\[
C=A[b_1,\ldots,b_m,c_1,\ldots,c_n].
\]
Thus finite generation of algebras is transitive.  This is the affine algebra behind stability of
locally finite-type morphisms under composition.

% VI26-DETAILED-EXERCISE-04
\paragraph{Solution 4.}
Let
\[
B=A[x_1,\ldots,x_n]/I.
\]
The quotient map sends the finitely many variables \(x_i\) to classes \(\bar x_i\), and by
Solution~1 these classes generate \(B\):
\[
B=A[\bar x_1,\ldots,\bar x_n].
\]
No finite-generation assumption on \(I\) is needed.  This is exactly the distinction between
\emph{finite type}, which controls algebra generators, and \emph{finite presentation}, which also
requires finitely many relations.

% VI26-DETAILED-EXERCISE-05
\paragraph{Solution 5.}
Let
\[
A=k[u_1,u_2,u_3,\ldots],
\qquad
I=(u_1,u_2,u_3,\ldots)\subset A,
\qquad
B=A/I\cong k.
\]
As an \(A\)-algebra, \(B\) is generated by no additional elements, so \(A\to B\) is of finite type.
The ideal \(I\) is not finitely generated: any finite collection of elements of \(I\) involves only
finitely many variables, say \(u_1,\ldots,u_N\), and therefore cannot generate \(u_{N+1}\).

For a surjective ring map \(A\twoheadrightarrow A/I\), finite presentation as an \(A\)-algebra is
equivalent to finite generation of the kernel ideal.  Indeed, one direction is immediate from the
presentation \(A/I=A/(I)\); conversely, any finite presentation can be transferred to the given
finite set of algebra generators, forcing the kernel of the surjection to be finitely generated.
Hence \(B\) is finite type but not finitely presented over \(A\).

% VI26-DETAILED-EXERCISE-06
\paragraph{Solution 6.}
Let \(f:X\to Y\) be finite type and let \(V=\Spec A\subseteq Y\) be affine.  By the affine-cover
criterion, \(f^{-1}(V)\) has a finite affine cover
\[
f^{-1}(V)=U_1\cup\cdots\cup U_r.
\]
Each affine \(U_i\) is quasi-compact, and a finite union of quasi-compact open subsets is
quasi-compact.  Thus \(f^{-1}(V)\) is quasi-compact for every affine \(V\subseteq Y\), which is the
quasi-compactness condition for the morphism.  This also recovers the ``finite type = locally finite
type + quasi-compact'' formulation.

% VI26-DETAILED-EXERCISE-07
\paragraph{Solution 7.}
Assume \(f:X\to Y\) is affine and locally of finite type.  For every affine open
\(V=\Spec A\subseteq Y\), affineness gives
\[
f^{-1}(V)=\Spec B
\]
for some \(A\)-algebra \(B\).  By the every-affine-open criterion for local finite type, \(B\) is
locally represented by finite-type affine charts; equivalently, the affine morphism is locally of
finite type over \(V\).  More simply, an affine morphism is quasi-compact because the inverse image
of every affine open is affine.  Hence \(f\) is locally finite type and quasi-compact, so it is
finite type.

% VI26-DETAILED-EXERCISE-08
\paragraph{Solution 8.}
Write the base change by \(S'\to S\).  The canonical Cartesian identity is
\[
\mathbb A^n_S\times_S S'\cong \mathbb A^n_{S'}.
\]
Affinely, if \(S=\Spec A\) and \(S'=\Spec A'\), then
\[
A[x_1,\ldots,x_n]\otimes_A A'
\cong
A'[x_1,\ldots,x_n].
\]
The right-hand side is generated by the \(n\) coordinate functions over \(A'\).  Therefore the
base-changed projection remains finite type.

% VI26-DETAILED-EXERCISE-09
\paragraph{Solution 9.}
Let \(A\) be Noetherian and \(S\subseteq A\) multiplicative.  Every ideal \(J\subseteq S^{-1}A\)
has the form
\[
J=S^{-1}I
\]
where \(I\) is its contraction to \(A\).  Since \(A\) is Noetherian,
\(I=(a_1,\ldots,a_r)\).  Localizing,
\[
J=(a_1/1,\ldots,a_r/1).
\]
Thus every ideal of \(S^{-1}A\) is finitely generated, so \(S^{-1}A\) is Noetherian.  In particular,
all distinguished affine opens of a Noetherian affine scheme are Noetherian.

% VI26-DETAILED-EXERCISE-10
\paragraph{Solution 10.}
Let \(A\) be Noetherian and let \(I\subseteq A\).  If \(J/I\) is an ideal of \(A/I\), its inverse
image \(J\subseteq A\) is an ideal containing \(I\).  Choose generators
\(J=(a_1,\ldots,a_r)\).  Their images generate \(J/I\).  Hence every ideal of \(A/I\) is finitely
generated, so \(A/I\) is Noetherian.  Equivalently, an ascending chain of ideals in \(A/I\) lifts
to one in \(A\) and therefore stabilizes.

% VI26-DETAILED-EXERCISE-11
\paragraph{Solution 11.}
Hilbert's basis theorem says that if \(R\) is Noetherian, then \(R[x]\) is Noetherian.  Starting from
the Noetherian ring \(A\), apply the theorem successively:
\[
A\;\Longrightarrow\;A[x_1]\;\Longrightarrow\;
A[x_1,x_2]\;\Longrightarrow\;\cdots\;\Longrightarrow\;
A[x_1,\ldots,x_n].
\]
After finitely many steps, \(A[x_1,\ldots,x_n]\) is Noetherian.

% VI26-DETAILED-EXERCISE-12
\paragraph{Solution 12.}
If \(B\) is a finite-type \(A\)-algebra, choose generators and obtain a surjection
\[
A[x_1,\ldots,x_n]\twoheadrightarrow B.
\]
When \(A\) is Noetherian, Solution~11 shows the polynomial ring is Noetherian.  By Solution~10 every
quotient of a Noetherian ring is Noetherian.  Therefore \(B\) is Noetherian.  This is the affine
form of the theorem that locally finite type over a locally Noetherian base gives a locally
Noetherian source.

% VI26-DETAILED-EXERCISE-13
\paragraph{Solution 13.}
In
\[
R=k[x_1,x_2,x_3,\ldots]
\]
consider \(I_n=(x_1,\ldots,x_n)\).  Clearly \(I_n\subseteq I_{n+1}\).  The inclusion is strict
because \(x_{n+1}\notin I_n\): setting \(x_1=\cdots=x_n=0\) gives a homomorphism
\[
R\longrightarrow k[x_{n+1},x_{n+2},\ldots]
\]
that annihilates \(I_n\) but not \(x_{n+1}\).  Hence
\[
I_1\subsetneq I_2\subsetneq I_3\subsetneq\cdots
\]
never stabilizes, so \(R\) is not Noetherian.

% VI26-DETAILED-EXERCISE-14
\paragraph{Solution 14.}
Let
\[
X=\coprod_{n\ge1}X_n,\qquad X_n=\Spec k.
\]
Each component \(X_n\) is open in \(X\), and the family \(\{X_n\}_{n\ge1}\) is an open cover.  A
finite subcollection covers only finitely many components and misses all the others.  Thus \(X\) is
not quasi-compact.  Consequently \(X\to\Spec k\) can be locally finite type without being finite
type.

% VI26-DETAILED-EXERCISE-15
\paragraph{Solution 15.}
Let \(X=X_1\amalg\cdots\amalg X_r\), with each \(X_i\to\Spec k\) finite type.  Each \(X_i\) is
quasi-compact and locally finite type.  Their finite disjoint union is again quasi-compact, and the
union of the finite-type affine covers of the \(X_i\) is still a finite affine cover of \(X\).
Therefore \(X\to\Spec k\) is finite type.

% VI26-DETAILED-EXERCISE-16
\paragraph{Solution 16.}
For \(f:X\to S\) and \(s\in S\),
\[
X_s=X\times_S\Spec\kappa(s).
\]
Thus the fiber is obtained by base change.  Finite-type morphisms are stable under arbitrary base
change, so
\[
X_s\longrightarrow\Spec\kappa(s)
\]
is finite type.  Affinely, \(B\) finite type over \(A\) implies
\(B\otimes_A\kappa(s)\) finite type over \(\kappa(s)\).

% VI26-DETAILED-EXERCISE-17
\paragraph{Solution 17.}
Let \(X\xrightarrow f Y\xrightarrow g Z\) be locally finite type.  Around a point of \(X\), choose
affine charts
\[
\Spec C\subseteq X,\qquad \Spec B\subseteq Y,\qquad \Spec A\subseteq Z
\]
compatible with the two maps, after shrinking by distinguished opens if necessary.  Then
\(B\) is finitely generated over \(A\) and \(C\) is finitely generated over \(B\).  By transitivity
of finite generation,
\[
C=A[b_1,\ldots,b_m,c_1,\ldots,c_n].
\]
Hence \(g\circ f\) is locally of finite type.

% VI26-DETAILED-EXERCISE-18
\paragraph{Solution 18.}
If \(f\) and \(g\) are finite type, Solution~17 gives that \(g\circ f\) is locally finite type.
Finite-type morphisms are quasi-compact, and the composite of two quasi-compact morphisms is
quasi-compact: the inverse image of a quasi-compact target open is quasi-compact under \(g\), and
its inverse image under \(f\) is again quasi-compact.  Therefore \(g\circ f\) is locally finite type
and quasi-compact, hence finite type.

% VI26-DETAILED-EXERCISE-19
\paragraph{Solution 19.}
Consider an affine part of a base-change square with
\[
A\to B,\qquad A\to A'.
\]
If \(B=A[b_1,\ldots,b_n]\), then every elementary tensor in \(B\otimes_AA'\) is obtained from
\(A'\) and the elements \(b_i\otimes1\).  More precisely,
\[
B\otimes_AA'=A'[b_1\otimes1,\ldots,b_n\otimes1].
\]
Thus the base-changed affine chart is finite type over \(A'\).  Refining arbitrary schemes by such
affine charts proves that locally finite type is stable under base change.

% VI26-DETAILED-EXERCISE-20
\paragraph{Solution 20.}
By Solution~19 the base change of a finite-type morphism is locally finite type.  Quasi-compactness
of morphisms is also stable under base change, so the pullback remains quasi-compact.  Therefore the
base-changed morphism is finite type.  Equivalently, over an affine target chart the original
finite affine cover pulls back to a finite affine cover with coordinate rings obtained by tensor
product.

% VI26-DETAILED-EXERCISE-21
\paragraph{Solution 21.}
Let \(U\subseteq X\) be open and suppose \(X\) is locally Noetherian.  For \(x\in U\), choose a
Noetherian affine neighborhood \(V=\Spec A\subseteq X\).  The open set \(U\cap V\) contains a
distinguished neighborhood \(D(f)\) of \(x\).  Its coordinate ring is \(A_f\), which is Noetherian
by Solution~9.  These distinguished opens cover \(U\), so \(U\) is locally Noetherian.

% VI26-DETAILED-EXERCISE-22
\paragraph{Solution 22.}
The underlying topological space of a Noetherian scheme is Noetherian.  In a Noetherian topological
space every open subset is quasi-compact.  One proof uses a maximal-counterexample argument: if an
open \(U\) had an open cover with no finite subcover, choose \(U\) maximal with this property.
Writing \(U=U_1\cup(U\setminus U_1)\) and applying maximality to the two proper opens gives finite
subcovers, a contradiction.  Hence every open subscheme of a Noetherian scheme is quasi-compact.

% VI26-DETAILED-EXERCISE-23
\paragraph{Solution 23.}
A field \(k\) is Noetherian.  If \(X\to\Spec k\) is finite type, then \(X\) is locally finite type
over the locally Noetherian base \(\Spec k\), so every affine chart has a finitely generated
\(k\)-algebra as coordinate ring and is Noetherian by Hilbert's basis theorem.  Moreover \(X\) is
quasi-compact because the structure morphism is finite type.  Thus \(X\) is a Noetherian scheme.

% VI26-DETAILED-EXERCISE-24
\paragraph{Solution 24.}
Take
\[
X=\coprod_{m\ge1}\mathbb A^1_k
\longrightarrow \Spec k.
\]
Each component \(\mathbb A^1_k\) is finite type over \(k\), so the structure morphism is locally
finite type.  However the components form an open cover with no finite subcover, so \(X\) is not
quasi-compact.  Hence the morphism is not finite type.

% VI26-DETAILED-EXERCISE-25
\paragraph{Solution 25.}
The projection
\[
\mathbb A^1_k=\Spec k[t]\longrightarrow\Spec k
\]
is finite type because \(k[t]\) is generated by \(t\) as a \(k\)-algebra.  It is not a finite
morphism: a finite morphism between affine schemes would require \(k[t]\) to be a finitely generated
\(k\)-module, but the linearly independent set \(1,t,t^2,\ldots\) shows this is impossible.

% VI26-DETAILED-EXERCISE-26
\paragraph{Solution 26.}
Finite type measures the number of \emph{algebra generators}, not the cardinality of the underlying
space or of a fiber.  For example,
\[
\mathbb A^1_k=\Spec k[t]\to\Spec k
\]
is generated by a single coordinate and is therefore finite type.  If \(k\) is infinite it already
has infinitely many \(k\)-rational points, and over an algebraic closure it still has infinitely many
geometric points.  Thus ``finite type'' means finite algebraic complexity of coordinates, not
finitely many points.
