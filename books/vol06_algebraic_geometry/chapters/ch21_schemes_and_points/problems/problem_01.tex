\subsection*{VI.21.P1: AG3 Problem 13: $\Spec\mathbb Z$ is final}
\begin{problem}\label{prob:vi21-p01}
Let $X$ be a scheme.  Prove that there exists a unique morphism
\[
X\longrightarrow\Spec\mathbb Z,
\]
identify it as the absolute structure morphism, describe it on affine charts and on points, and prove its naturality in $X$.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
This is the absolute base of scheme theory.  The point is not merely that affine charts map to $\Spec\mathbb Z$, but that the map is canonical for every scheme and every morphism respects it.

\paragraph{Useful ideas before starting.}
Translate point statements through local rings and residue fields; when the target is affine, use the VI/19 universal property and then verify the pointwise interpretation.

\paragraph{Guided hints.}
\begin{enumerate}
\item Identify the relevant canonical ring or stalk homomorphism.
\item Track maximal ideals or prime contractions to identify the image point.
\item Use locality to pass to residue fields when needed.
\item Check independence, uniqueness, or functoriality explicitly rather than only on points.
\end{enumerate}

\begin{solution}
The key input is the universal property of an affine target from VI/19, which applies to an arbitrary locally ringed source.  Since a scheme is a locally ringed space,
\[
\operatorname{Hom}_{\mathbf{Sch}}(X,\Spec\mathbb Z)
=\operatorname{Hom}_{\mathrm{LRS}}(X,\Spec\mathbb Z)
\cong
\operatorname{Hom}_{\mathbf{Ring}}(\mathbb Z,\Gamma(X,\OO_X)).
\]
For every unital ring $R$ there is exactly one unital homomorphism $\mathbb Z\to R$, namely
$n\mapsto n1_R$.  Thus the Hom-set on the left has exactly one element.  Denote that unique
morphism by
\[
\pi_X:X\longrightarrow\Spec\mathbb Z.
\]
This proves both existence and uniqueness for an arbitrary scheme, not only for an affine one.

Now let $U=\Spec A\subseteq X$ be an affine open.  The restriction
$\pi_X|_U:U\to\Spec\mathbb Z$ is a morphism from $U$ to the final target, so by uniqueness it is
the affine morphism induced by the canonical ring map
\[
\mathbb Z\longrightarrow A,\qquad n\longmapsto n1_A.
\]
Consequently, if $x\in U$ corresponds to $\mathfrak p\in\Spec A$, then
\[
\pi_X(x)=\mathfrak p\cap\mathbb Z.
\]
Equivalently, using the residue field at $x$,
\[
\pi_X(x)=\ker(\mathbb Z\to\kappa(x)).
\]
Thus points of residue characteristic $0$ map to $(0)$ and points of residue characteristic
$p$ map to $(p)$.

Finally let $f:X\to Y$ be any scheme morphism.  Both $\pi_X$ and
$\pi_Y\circ f$ are morphisms $X\to\Spec\mathbb Z$.  By uniqueness,
\[
\pi_X=\pi_Y\circ f.
\]
Hence the construction is natural in $X$.  This is precisely the categorical statement that
$\Spec\mathbb Z$ is a final object of $\mathbf{Sch}$, reflecting contravariantly that
$\mathbb Z$ is initial in unital commutative rings.
\end{solution}

\paragraph{What happened mathematically.}
This is the absolute base of scheme theory.  The point is not merely that affine charts map to $\Spec\mathbb Z$, but that the map is canonical for every scheme and every morphism respects it.

\paragraph{Extensions.}
Use the result to derive the residue-characteristic map and to explain why every scheme morphism is automatically a morphism over $\Spec\mathbb Z$.
