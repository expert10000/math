\subsection*{VI.21.P16: Pointwise residue characteristic versus scheme-theoretic characteristic}
\begin{problem}\label{prob:vi21-p16}
Assume every $x\in X$ has residue field of characteristic $p$.  Determine the point-set image of $X\to\Spec\mathbb Z$, give an example showing that this need not imply factorization through $\Spec\mathbb F_p$, and state the correct criterion.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
It isolates the difference between the topological image of the absolute structure morphism and an actual factorization of locally ringed spaces.

\paragraph{Useful ideas before starting.}
Translate point statements through local rings and residue fields; when the target is affine, use the VI/19 universal property and then verify the pointwise interpretation.

\paragraph{Guided hints.}
\begin{enumerate}
\item Identify the relevant canonical ring or stalk homomorphism.
\item Track maximal ideals or prime contractions to identify the image point.
\item Use locality to pass to residue fields when needed.
\item Check independence, uniqueness, or functoriality explicitly rather than only on points.
\end{enumerate}

\begin{solution}
For every point $x$, the structure morphism satisfies
\[
\pi_X(x)=\ker(\mathbb Z\to\kappa(x))=(p).
\]
Hence the underlying image is contained in $\{(p)\}$ and equals that singleton when $X$ is
nonempty.

Now take
\[
X=\Spec(\mathbb Z/p^2\mathbb Z).
\]
This ring has the unique prime $(p)/(p^2)$, whose residue field is $\mathbb F_p$.  Thus every
residue field has characteristic $p$.  Nevertheless $p\cdot1\neq0$ in
$\mathbb Z/p^2\mathbb Z$, so the canonical ring map $\mathbb Z\to\mathbb Z/p^2\mathbb Z$ does not
factor through $\mathbb F_p$.  Contravariantly, $\pi_X$ does not factor through
$\Spec\mathbb F_p$.

The correct criterion is
\[
p\cdot1=0\quad\text{in }\Gamma(X,\OO_X).
\]
Equivalently, the global section $p\cdot1$ has zero germ in every stalk.  This stronger condition
controls the entire scheme structure rather than only the residue fields.
\end{solution}

\paragraph{What happened mathematically.}
It isolates the difference between the topological image of the absolute structure morphism and an actual factorization of locally ringed spaces.

\paragraph{Extensions.}
Construct analogous examples using higher $p$-power thickenings.
