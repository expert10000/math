\begin{problem}[Principal opens in the dual numbers]
Let
\[
A=k[\varepsilon]/(\varepsilon^2).
\]
Determine $D(\varepsilon)$ and $D(1+\varepsilon)$, compute $A_\varepsilon$, and compare
$D(f)$ for an arbitrary element $f=a+b\varepsilon$ according to whether $a=0$ or $a\neq0$.
\end{problem}

\paragraph{Why this problem matters.}
A one-point nonreduced spectrum shows sharply what principal opens can and cannot see.
Nilpotent directions affect the ring but not the underlying open subsets.

\paragraph{Useful ideas before starting.}
The unique prime ideal is $(\varepsilon)$.  An element $a+b\varepsilon$ is a unit iff
$a\neq0$.

\paragraph{Guided hints.}
If a nilpotent element becomes invertible, then $0$ becomes invertible.

\begin{solution}
The class $\varepsilon$ is nilpotent, so it belongs to every prime ideal.  Therefore
\[
D(\varepsilon)=\varnothing.
\]
Localizing at $\varepsilon$ forces $\varepsilon$ to be a unit.  Since
$\varepsilon^2=0$, multiplying by $\varepsilon^{-2}$ would force $1=0$; equivalently the
localization is the zero ring:
\[
A_\varepsilon=0.
\]

The element $1+\varepsilon$ is a unit because
\[
(1+\varepsilon)(1-\varepsilon)=1.
\]
Hence
\[
D(1+\varepsilon)=\Spec A.
\]

More generally, if $f=a+b\varepsilon$ with $a\neq0$, then
\[
f=a\left(1+a^{-1}b\varepsilon\right)
\]
is a unit, so $D(f)=\Spec A$.  If $a=0$, then $f=b\varepsilon$ is nilpotent (or zero), so
$D(f)=\varnothing$.  Thus this nonreduced one-point spectrum has only two principal opens:
$\varnothing$ and the whole space.
\end{solution}

\paragraph{What happened mathematically.}
The topology sees only whether an element is a unit or lies in the nilpotent maximal ideal;
it does not measure infinitesimal thickness.

\paragraph{Extensions.}
Repeat the analysis for $k[\varepsilon]/(\varepsilon^n)$.

\paragraph{Provenance.}
New canonical problem based on the legacy nonreduced localization examples; the systematic
study of nilpotent geometry remains reserved for VI/10.
