\begin{problem}[Challenge: one-point local Artin rings]
For $n\ge2$ set $R_n=k[\varepsilon]/(\varepsilon^n)$.  Show all $\Spec R_n$ are the same one-point topological space with residue field $k$, but the filtered local rings $(R_n,(\varepsilon))$ are pairwise nonisomorphic.  Determine the dimensions of $\mathfrak m^i/\mathfrak m^{i+1}$.
\end{problem}

\paragraph{Why this problem matters.}
It asks for a precise invariant of infinitesimal thickness beyond points and residue fields.

\paragraph{Useful ideas before starting.}
Use the nilpotency index of the maximal ideal and the associated graded ring.

\paragraph{Guided hints.}
Each quotient $\mathfrak m^i/\mathfrak m^{i+1}$ is spanned by $\varepsilon^i$.

\begin{solution}
Each $R_n$ has unique prime/maximal ideal $\mathfrak m=(\varepsilon)$ and residue field $k$.  But $\mathfrak m^n=0$ while $\mathfrak m^{n-1}\neq0$, so the nilpotency index determines $n$ and proves pairwise nonisomorphism.  Moreover each $\mathfrak m^i/\mathfrak m^{i+1}$ for $0\le i<n$ is one-dimensional over $k$, generated by the class of $\varepsilon^i$.
\end{solution}

\paragraph{What happened mathematically.}
The associated graded ring records infinitesimal layers invisible to the underlying point.
