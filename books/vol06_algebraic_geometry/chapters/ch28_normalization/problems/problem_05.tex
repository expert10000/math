\begin{problem}[VI.28.P5: Normality iff normalization is trivial]\label{prob:vi28-05}
Show that an integral scheme $X$ is normal if and only if its normalization morphism $X^\nu\to X$ is an isomorphism.

\textbf{Provenance.} Canonical dossier.
\end{problem}
\begin{solution}
If $X$ is normal, every affine coordinate domain equals its integral closure, so the normalization is locally and hence globally an isomorphism.  Conversely, if $X^\nu\to X$ is an isomorphism, every affine chart identifies with a normal affine chart of $X^\nu$, so $X$ is normal.
\end{solution}
