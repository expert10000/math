\begin{problem}[VI.28.P9: Same function field]\label{prob:vi28-09}
Prove globally that $K(X^\nu)\cong K(X)$ canonically.

\textbf{Provenance.} Canonical dossier.
\end{problem}
\begin{solution}
On any nonempty affine chart $U=\Spec A$, the normalized chart has coordinate ring $\overline A\subseteq\Frac(A)$ and $\Frac(\overline A)=\Frac(A)$.  Both fields identify with the corresponding generic stalks.  These affine identifications agree on overlaps, giving the canonical global identification.
\end{solution}
