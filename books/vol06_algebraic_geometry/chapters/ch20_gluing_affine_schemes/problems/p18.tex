\begin{problem}[Why the cocycle is necessary]\label{prob:vi20-p18}
Construct an abstract three-chart scenario showing that pairwise inverse maps without the cocycle need not define the prescribed gluing.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
The cocycle is structural, not cosmetic.

\paragraph{Useful ideas before starting.}
Track one point around a triple overlap.

\paragraph{Guided hints.}
\begin{enumerate}
\item Track one point around a triple overlap.
\end{enumerate}

\begin{solution}
Choose a point $x$ in a triple overlap for which $\varphi_{13}(x)\ne\varphi_{23}(\varphi_{12}(x))$.  Any equivalence relation containing both pairwise identifications forces $x$ to be equivalent to both points in chart 3, thereby collapsing points beyond the prescribed $\varphi_{13}$ identification.  Consequently the chart maps cannot remain injective with the requested overlaps.  The cocycle prevents this inconsistency.
\end{solution}

\paragraph{What happened mathematically.}
Triple coherence is exactly what allows pairwise data to globalize.
