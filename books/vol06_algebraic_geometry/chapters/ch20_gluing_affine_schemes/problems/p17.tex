\begin{problem}[Gluing along the whole chart]\label{prob:vi20-p17}
If $\varphi:X_1\to X_2$ is an isomorphism, glue along $U_{12}=X_1$, $U_{21}=X_2$ and identify the result.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
This checks the opposite extreme boundary case.

\paragraph{Useful ideas before starting.}
Every point and every local function is identified by $\varphi$.

\paragraph{Guided hints.}
\begin{enumerate}
\item Every point and every local function is identified by $\varphi$.
\end{enumerate}

% VI20_FULL_SOLUTION_REFINEMENT P17
\begin{solution}
Let $\varphi:X_1\xrightarrow{\sim}X_2$ and glue with $U_{12}=X_1$, $U_{21}=X_2$.  Every $x\in X_1$ is identified with exactly $\varphi(x)\in X_2$, and there are no additional points outside the overlap.  Therefore the quotient map
\[
\psi_1:X_1\longrightarrow X
\]
is bijective.  Its image is open and equals all of $X$, and the quotient topology makes $\psi_1$ a homeomorphism.  The same is true of $\psi_2$.

For the structure sheaf, a section is a pair $(s_1,s_2)$ with $s_1=\varphi^\sharp(s_2)$ under the full-chart identification.  Thus either component determines the other uniquely.  Consequently $\psi_1$ identifies $\OO_X$ with $\OO_{X_1}$, so it is an isomorphism of schemes.  Similarly $\psi_2$ is an isomorphism.  Under these identifications the comparison $X_1\to X_2$ is exactly the original $\varphi$.  Hence full-overlap gluing simply removes the duplicate presentation.
\end{solution}


\paragraph{What happened mathematically.}
Full-overlap gluing forgets the duplicate chart.

\paragraph{Extensions.}
Use this to justify redundant-chart invariance.
