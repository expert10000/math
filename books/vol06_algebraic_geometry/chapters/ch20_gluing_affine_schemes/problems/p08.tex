\begin{problem}[Two-chart projective-line model]\label{prob:vi20-p08}
Glue $\Spec k[t]$ and $\Spec k[u]$ along punctured lines using $u=t^{-1}$. Describe the points and overlap functions.
\end{problem}

\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.}
This previews projective geometry using only affine gluing.

\paragraph{Useful ideas before starting.}
The overlap rings are Laurent polynomial rings.

\paragraph{Guided hints.}
\begin{enumerate}
\item The overlap rings are Laurent polynomial rings.
\end{enumerate}

\begin{solution}
Use $k[u,u^{-1}]\to k[t,t^{-1}]$, $u\mapsto t^{-1}$.  The gluing keeps one origin from each chart and identifies every nonzero coordinate point by reciprocal coordinates.  Regular functions on the overlap transform by substitution $u=t^{-1}$.  The result is a scheme covered by two affine lines; its later identification with $\PP^1_k$ is deferred.
\end{solution}

\paragraph{What happened mathematically.}
A global compact-looking object emerges from two elementary affine charts.

\paragraph{Extensions.}
Compute its global sections.
