# Volume VI chapter sources

This directory contains only **canonical reconstructed chapters**.

## Naming rule

Use:

```text
chNN_short_topic/
├── chapter.tex
├── examples.tex
├── exercises.tex
├── hints.tex
├── solutions.tex
└── figures/
```

For example:

```text
ch08_basic_open_sets/
```

corresponds to canonical chapter `VI/08`.

Legacy files under `chapters/tex/` are source material and must not be copied here wholesale. Their content is migrated according to `editorial/SOURCE_MIGRATION.tsv`.
