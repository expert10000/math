\begin{problem}[VI.37.P2: Projective conic charts]\label{prob:vi37-02}
For \(X=V_+(XZ-Y^2)\subseteq\mathbb P^2_k\), compute all three standard affine charts.
\begin{solution}
On \(X\ne0\), set \(y=Y/X,z=Z/X\); the equation is \(z-y^2=0\).  On \(Y\ne0\), set \(x=X/Y,z=Z/Y\); the equation is \(xz-1=0\).  On \(Z\ne0\), set \(x=X/Z,y=Y/Z\); the equation is \(x-y^2=0\).  These agree on overlaps by the projective transition maps.
\end{solution}
\end{problem}
