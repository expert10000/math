\begin{problem}[VI.34.P5: A conic chart]\label{prob:vi34-05}
Let \(S=k[x,y,z]/(xz-y^2)\). Compute \(S_{(x)}\), \(S_{(z)}\), and their common overlap.
\begin{solution}
Set \(u=y/x\), so \(z/x=u^2\), giving \(S_{(x)}\cong k[u]\). Similarly \(S_{(z)}\cong k[v]\). On the overlap \(v=u^{-1}\), so both localize to \(k[u,u^{-1}]\).
\end{solution}
\end{problem}
