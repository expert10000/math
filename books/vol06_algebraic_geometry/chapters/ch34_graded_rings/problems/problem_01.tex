\begin{problem}[VI.34.P1: Homogeneous ideals from components]\label{prob:vi34-01}
Let \(S=\bigoplus S_n\) and \(I\subseteq S\). Prove the equivalence of the three conditions in the component criterion.
\begin{solution}
Generation by homogeneous elements implies the component property by decomposing coefficients and grouping by total degree. The component property is equivalent to \(I=\bigoplus(I\cap S_n)\). That direct-sum description says every element of \(I\) is a sum of homogeneous elements of \(I\), so homogeneous elements generate \(I\).
\end{solution}
\end{problem}
