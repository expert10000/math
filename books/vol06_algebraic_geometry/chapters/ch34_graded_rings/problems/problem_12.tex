\begin{problem}[VI.34.P12: Design of the future standard open]\label{prob:vi34-12}
Using VI/33 and this chapter, formulate the ring and module that should live on a future basic projective open and state the required overlap compatibility.
\begin{solution}
Use \(S_{(f)}=(S_f)_0\) and \(M_{(f)}=(M_f)_0\). Further homogeneous localization must identify these objects on overlaps, which is the algebraic input for gluing affine schemes and quasi-coherent module sheaves in VI/35.
\end{solution}
\end{problem}
