\subsection*{Problem VI.03.P7 --- Every function on \(\mathbb F_q\) is polynomial}
\label{prob:vi03-p7}
\paragraph{Problem.}
Prove that every function \(\mathbb F_q\to\mathbb F_q\) is represented by a unique
polynomial of degree \(<q\).  Deduce
\[
\mathbb F_q[x]/(x^q-x)\cong\prod_{a\in\mathbb F_q}\mathbb F_q.
\]
\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.} It makes the finite-field phenomenon concrete: polynomial functions and arbitrary functions coincide on a finite affine line.
\paragraph{Useful ideas before starting.} Use Lagrange interpolation and the factorization \(x^q-x=\prod_a(x-a)\).
\paragraph{Guided hints.} Interpolate prescribed values; uniqueness follows because a nonzero polynomial of degree below \(q\) has fewer than \(q\) roots.
\paragraph{Solution.}
For a function \(h\), define
\[
P_h(x)=\sum_{a\in\mathbb F_q}h(a)\prod_{b\neq a}\frac{x-b}{a-b}.
\]
Then \(\deg P_h<q\) and \(P_h(a)=h(a)\).  If two such polynomials represent the same
function, their difference has \(q\) roots and degree below \(q\), so it is zero.  Thus the
reduced representatives modulo \(x^q-x\) are exactly all functions.  CRT applied to
\(x^q-x=\prod_a(x-a)\) gives the product decomposition.
\paragraph{What happened mathematically.} The quotient has dimension \(q\) over \(\mathbb F_q\), exactly the number of independent function values.
\paragraph{Extensions.} Generalize to \(\mathbb F_q^n\) in Challenge VI.03.C2.
\paragraph{Provenance.} New synthesis problem extending the chapter's finite-field example.
\fi
