\subsection*{Problem VI.03.P5 --- The union of two axes as glued polynomial pairs}
\label{prob:vi03-p5}
\paragraph{Problem.}
Assume \(k\) is algebraically closed and set \(X=V(xy)\subseteq\mathbb A_k^2\).  Prove
\[
k[X]\cong\set{(f,g)\in k[x]\times k[y]:f(0)=g(0)}.
\]
\ifdefined\FullProblemDossiers
\paragraph{Why this problem matters.} The ring records two components together with the rule that their functions agree where the components meet.
\paragraph{Useful ideas before starting.} Restrict a class \([F(x,y)]\) to the \(x\)-axis and the \(y\)-axis.
\paragraph{Guided hints.} Define \([F]\mapsto(F(x,0),F(0,y))\).  For surjectivity, use \(f(x)+g(y)-c\) when \(f(0)=g(0)=c\).
\paragraph{Solution.}
Define
\[
\Phi:k[x,y]/(xy)\to k[x]\times k[y],\qquad [F]\mapsto(F(x,0),F(0,y)).
\]
Its image lies in the displayed subring because both components have value \(F(0,0)\) at
the origin.  If \(\Phi([F])=(0,0)\), then \(F(x,0)=0\), so \(F\in(y)\), while
\(F(0,y)=0\), so \(F\in(x)\).  Since \((x)\cap(y)=(xy)\) in \(k[x,y]\), we get
\(F\in(xy)\).  Hence \(\Phi\) is injective.  Given \((f,g)\) with common value \(c\), the polynomial
\(f(x)+g(y)-c\) restricts to \(f\) and \(g\), proving surjectivity.
\paragraph{What happened mathematically.} A polynomial function on the union is a pair of polynomial functions on the components that agree on their intersection.
\paragraph{Extensions.} Generalize to the union of \(n\) coordinate axes; see Challenge VI.03.C3.
\paragraph{Provenance.} New synthesis problem preparing the irreducibility/component discussion of VI/05.
\fi
