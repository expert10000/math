\chapter{Coordinate Rings}
\label{ch:coordinate-rings}

\section*{Purpose and learning goals}

An affine algebraic set is specified by polynomial equations.  The coordinate ring turns
that geometric object back into algebra: it records polynomial functions on the set, with
two polynomials identified when they agree at every point.

This construction is the first serious form of the algebra--geometry dictionary.  A
geometric set \(X\) gives a ring \(k[X]\), and geometric information about \(X\) becomes
encoded in algebraic properties of \(k[X]\).

Throughout, \(k\) is a field and
\[
X\subseteq \mathbb A_k^n
\]
is an affine algebraic set unless stated otherwise.

After this chapter, the reader should be able to:
\begin{itemize}
  \item define polynomial functions on an algebraic set;
  \item prove that the kernel of restriction to \(X\) is \(I(X)\);
  \item construct
        \[
        k[X]=k[x_1,\dots,x_n]/I(X);
        \]
  \item compute coordinate rings in standard examples;
  \item recognize coordinate rings as finitely generated reduced \(k\)-algebras;
  \item recover \(I(X)\) as the relations among the coordinate functions;
  \item distinguish the coordinate ring from a chosen presentation of that ring;
  \item explain why nilpotent information is absent from classical algebraic sets.
\end{itemize}

\section{Polynomial functions on an algebraic set}

A polynomial in the ambient variables restricts to a function on \(X\).

\begin{definition}[Polynomial function]
Let \(X\subseteq\mathbb A_k^n\).  A function
\[
\varphi:X\longrightarrow k
\]
is called a \emph{polynomial function} if there exists
\[
f\in k[x_1,\dots,x_n]
\]
such that
\[
\varphi(a)=f(a)
\]
for every \(a\in X\).
\end{definition}

The polynomial representing a polynomial function need not be unique.

\begin{example}
Let
\[
X=V(y-x^2)\subseteq\mathbb A_k^2.
\]
On \(X\), the two ambient polynomials \(y\) and \(x^2\) define the same function because
\[
y-x^2
\]
vanishes at every point of \(X\).
\end{example}

This observation motivates the quotient construction.

\section{Restriction and its kernel}

Consider the restriction map
\[
\rho_X:
k[x_1,\dots,x_n]
\longrightarrow
\operatorname{Fun}(X,k),
\qquad
f\longmapsto f|_X,
\]
where \(\operatorname{Fun}(X,k)\) denotes all set-theoretic functions \(X\to k\).

The image consists exactly of the polynomial functions on \(X\).

\begin{proposition}[Kernel of restriction]
\label{prop:vi03-kernel-restriction}
The kernel of \(\rho_X\) is the vanishing ideal:
\[
\ker\rho_X=I(X).
\]
\end{proposition}

\begin{proof}
A polynomial \(f\) lies in \(\ker\rho_X\) exactly when
\[
f(a)=0
\]
for every \(a\in X\).  This is precisely the definition of \(I(X)\).
\end{proof}

Therefore two polynomials \(f,g\) determine the same polynomial function on \(X\) exactly
when
\[
f-g\in I(X).
\]

Equivalently,
\[
f|_X=g|_X
\quad\Longleftrightarrow\quad
f\equiv g\pmod{I(X)}.
\]

\section{Definition of the coordinate ring}

\begin{definition}[Coordinate ring]
The \emph{coordinate ring} of an affine algebraic set
\[
X\subseteq\mathbb A_k^n
\]
is
\[
k[X]
:=
k[x_1,\dots,x_n]/I(X).
\]
It is also called the \emph{affine coordinate ring} of \(X\).
\end{definition}

By the first isomorphism theorem, \(k[X]\) is naturally isomorphic to the ring of
polynomial functions on \(X\):
\[
k[X]
\cong
\operatorname{im}(\rho_X).
\]

Thus an element of \(k[X]\) may be viewed in three equivalent ways:

\[
\boxed{
\begin{array}{c}
\text{a residue class }[f]\text{ modulo }I(X),\\[0.4em]
\text{a polynomial expression restricted to }X,\\[0.4em]
\text{a polynomial function }X\to k.
\end{array}
}
\]

\begin{remark}
The quotient notation is not bookkeeping.  It encodes all polynomial relations that hold on
\(X\).
\end{remark}

\section{Coordinate functions and relations}

Let
\[
\bar x_i
\]
denote the residue class of \(x_i\) in \(k[X]\).  These are the canonical coordinate
functions on \(X\).

They generate \(k[X]\) as a \(k\)-algebra:
\[
k[X]=k[\bar x_1,\dots,\bar x_n].
\]

All algebraic relations among them come from \(I(X)\).

\begin{proposition}[Relations among coordinates]
\label{prop:vi03-relations}
For
\[
F\in k[t_1,\dots,t_n],
\]
one has
\[
F(\bar x_1,\dots,\bar x_n)=0
\quad\text{in }k[X]
\]
if and only if
\[
F(x_1,\dots,x_n)\in I(X).
\]
\end{proposition}

\begin{proof}
The quotient map
\[
k[x_1,\dots,x_n]\to k[X]
\]
has kernel \(I(X)\).  The element
\[
F(\bar x_1,\dots,\bar x_n)
\]
is the image of \(F(x_1,\dots,x_n)\), so it is zero exactly when that polynomial belongs
to the kernel.
\end{proof}

\begin{example}[Parabola]
For
\[
X=V(y-x^2),
\]
the coordinate functions satisfy
\[
\bar y=\bar x^2.
\]
Hence
\[
k[X]
=
k[x,y]/(y-x^2).
\]
Eliminating \(y\) gives an isomorphism
\[
k[X]\cong k[t].
\]
\end{example}

\section{Basic examples}

\begin{example}[Affine space]
Since
\[
I(\mathbb A_k^n)=(0)
\]
when \(k\) is infinite,
\[
k[\mathbb A_k^n]
\cong
k[x_1,\dots,x_n].
\]
For finite \(k\), the classical ring of polynomial functions on the finite point set is a
different quotient; this field-dependent phenomenon is discussed later in the chapter.
\end{example}

\begin{example}[A point]
For
\[
a=(a_1,\dots,a_n)\in\mathbb A_k^n,
\]
\[
I(\{a\})
=
(x_1-a_1,\dots,x_n-a_n).
\]
Therefore
\[
k[\{a\}]
=
k[x_1,\dots,x_n]/
(x_1-a_1,\dots,x_n-a_n)
\cong k.
\]
\end{example}

\begin{example}[A coordinate line]
Let
\[
L=V(y)\subseteq\mathbb A_k^2.
\]
Then
\[
k[L]
=
k[x,y]/(y)
\cong
k[x].
\]
\end{example}

\begin{example}[Two coordinate axes]
Let
\[
X=V(xy)\subseteq\mathbb A_k^2.
\]
If the base field is such that
\[
I(X)=(xy)
\]
(for example over an algebraically closed field), then
\[
k[X]
=
k[x,y]/(xy).
\]
The classes \(\bar x,\bar y\) are both nonzero, but
\[
\bar x\bar y=0.
\]
Thus the coordinate ring has zero divisors, reflecting the decomposition of \(X\) into two
components.
\end{example}

\section{Finitely generated \texorpdfstring{\(k\)}{k}-algebras}

\begin{definition}[Finitely generated \(k\)-algebra]
A \(k\)-algebra \(A\) is \emph{finitely generated} if there exist
\(a_1,\dots,a_n\in A\) such that
\[
A=k[a_1,\dots,a_n].
\]
\end{definition}

\begin{proposition}
\label{prop:vi03-fg}
The coordinate ring of every affine algebraic set is a finitely generated \(k\)-algebra.
\end{proposition}

\begin{proof}
By definition,
\[
k[X]=k[x_1,\dots,x_n]/I(X),
\]
and the residue classes
\[
\bar x_1,\dots,\bar x_n
\]
generate the quotient as a \(k\)-algebra.
\end{proof}

Conversely, every finitely generated commutative \(k\)-algebra has a presentation
\[
A\cong k[x_1,\dots,x_n]/J
\]
for some ideal \(J\).

This is an algebraic statement.  Turning such a presentation into a classical affine
algebraic set requires care: the set
\[
V(J)
\]
remembers only the radical information visible in \(k\)-rational points.  Scheme theory
will later allow arbitrary finitely generated \(k\)-algebras to serve directly as affine
geometric objects.

\section{Reducedness}

Chapter VI/01 showed that \(I(X)\) is radical.

\begin{proposition}[Coordinate rings of classical algebraic sets are reduced]
\label{prop:vi03-reduced}
For every affine algebraic set \(X\),
\[
k[X]
\]
has no nonzero nilpotent elements.
\end{proposition}

\begin{proof}
Since \(I(X)\) is radical, suppose
\[
[f]^m=0
\]
in \(k[X]\).  Then
\[
f^m\in I(X).
\]
Radicality gives
\[
f\in I(X),
\]
hence
\[
[f]=0.
\]
\end{proof}

\begin{remark}[Why schemes later enlarge the category]
The quotients
\[
k[x]/(x)
\qquad\text{and}\qquad
k[x]/(x^2)
\]
have the same classical zero set, but the second ring contains a nonzero nilpotent class.
Classical algebraic sets discard this infinitesimal information.  Affine schemes will retain
it.
\end{remark}

\section{Presentations are not intrinsic}

An algebraic set may admit different embeddings into affine spaces, leading to different
polynomial presentations of the same abstract ring.

\begin{example}[The parabola again]
The parabola
\[
X=V(y-x^2)\subseteq\mathbb A_k^2
\]
has
\[
k[X]=k[x,y]/(y-x^2).
\]
But
\[
k[x,y]/(y-x^2)\cong k[t].
\]
So its coordinate ring can be presented either with two generators and one relation or with
one generator and no relation.
\end{example}

This distinction will matter in VI/04.  Geometry should not depend on a particular choice
of coordinates or presentation.

\section{Quotient maps and evaluation}

Let
\[
\pi_X:
k[x_1,\dots,x_n]\to k[X]
\]
be the quotient map.

For every point \(a\in X\), evaluation at \(a\) descends to a \(k\)-algebra map
\[
\operatorname{ev}_a:
k[X]\to k,
\qquad
[f]\longmapsto f(a).
\]

\begin{proposition}[Evaluation is well-defined]
\label{prop:vi03-evaluation}
The map \(\operatorname{ev}_a\) is a well-defined \(k\)-algebra homomorphism.
\end{proposition}

\begin{proof}
If
\[
[f]=[g]
\]
in \(k[X]\), then
\[
f-g\in I(X),
\]
so in particular
\[
f(a)-g(a)=0.
\]
Thus the value depends only on the residue class.  The ring and \(k\)-algebra properties
follow from ordinary polynomial evaluation.
\end{proof}

Its kernel is
\[
\mathfrak m_a
=
\set{\varphi\in k[X]\mid \varphi(a)=0}.
\]

Because
\[
k[X]/\mathfrak m_a\cong k,
\]
the ideal \(\mathfrak m_a\) is maximal.

This is an early indication that points can be encoded algebraically by maximal ideals.
Prime ideals and the full spectrum are postponed to VI/06--VI/09.

\section{The coordinate ring of a closed subset}

Suppose
\[
Y\subseteq X\subseteq\mathbb A_k^n
\]
are algebraic sets.

The inclusion of vanishing ideals reverses:
\[
I(X)\subseteq I(Y).
\]

Therefore the quotient map induces a surjection
\[
k[X]\twoheadrightarrow k[Y].
\]

\begin{proposition}[Closed subsets give quotient rings]
\label{prop:vi03-closed-subset-quotient}
Let \(Y\subseteq X\) be algebraic.  Define
\[
I_X(Y)
=
I(Y)/I(X)
\subseteq
k[X].
\]
Then
\[
k[Y]
\cong
k[X]/I_X(Y).
\]
\end{proposition}

\begin{proof}
The natural map
\[
k[x_1,\dots,x_n]/I(X)
\longrightarrow
k[x_1,\dots,x_n]/I(Y)
\]
is surjective because
\[
I(X)\subseteq I(Y).
\]
Its kernel is exactly
\[
I(Y)/I(X).
\]
The first isomorphism theorem gives the result.
\end{proof}

This is a fundamental reversal:

\[
\boxed{
Y\subseteq X
\quad\Longrightarrow\quad
k[X]\twoheadrightarrow k[Y].
}
\]

Geometric inclusion becomes algebraic quotient.

\section{Products and separated variables}

For affine spaces,
\[
k[\mathbb A_k^m\times\mathbb A_k^n]
\cong
k[x_1,\dots,x_m,y_1,\dots,y_n].
\]

More generally, coordinate rings of products are closely related to tensor products.
The systematic statement belongs naturally with morphisms and categorical constructions, so
we postpone it until the algebra--geometry correspondence has been developed further.

For now, an elementary case is useful.

\begin{example}
Let
\[
X=V(f(x))\subseteq\mathbb A_k^1,
\qquad
Y=V(g(y))\subseteq\mathbb A_k^1.
\]
Then
\[
X\times Y
\subseteq
\mathbb A_k^2
\]
is cut out by
\[
f(x)=0,\qquad g(y)=0.
\]
Under the expected radical hypotheses,
\[
k[X\times Y]
\cong
k[x,y]/(f(x),g(y)).
\]
\end{example}

\section{What changes over finite fields?}

Over an infinite field, a polynomial that vanishes on all of
\[
\mathbb A_k^n
\]
is the zero polynomial, so
\[
I(\mathbb A_k^n)=(0).
\]

Over a finite field this fails.

\begin{example}
Over \(\mathbb F_p\),
\[
x^p-x
\]
vanishes at every element of \(\mathbb F_p\).  Hence
\[
x^p-x\in I(\mathbb A^1_{\mathbb F_p}).
\]
Indeed,
\[
I(\mathbb A^1_{\mathbb F_p})=(x^p-x).
\]
Thus the ring of polynomial functions on the finite point set is
\[
\mathbb F_p[x]/(x^p-x),
\]
not the full polynomial ring.
\end{example}

For several variables,
\[
I(\mathbb A^n_{\mathbb F_q})
=
(x_1^q-x_1,\dots,x_n^q-x_n).
\]

This distinction is important: the \emph{classical coordinate ring of the rational point
set} depends on the chosen field of points.  Later scheme-theoretic affine space is defined
instead from the polynomial ring itself and does not collapse these functions.

\section{The algebra--geometry dictionary so far}

The first three chapters now give:

\[
\boxed{
\begin{array}{c|c}
\text{Geometry} & \text{Algebra}\\
\hline
X\subseteq\mathbb A_k^n & I(X)\subseteq k[x_1,\dots,x_n]\\[0.2em]
X=V(I) & \text{polynomial equations}\\[0.2em]
\overline{Y}^{\,\mathrm{Zar}} & V(I(Y))\\[0.2em]
X & k[X]=k[x_1,\dots,x_n]/I(X)\\[0.2em]
\text{coordinate functions} & \bar x_1,\dots,\bar x_n\\[0.2em]
Y\subseteq X\text{ closed} & k[X]\twoheadrightarrow k[Y]\\[0.2em]
a\in X & \operatorname{ev}_a:k[X]\to k
\end{array}
}
\]

The next chapter adds the most important contravariant step: a polynomial/regular map
\[
X\to Y
\]
will induce a \(k\)-algebra homomorphism in the opposite direction
\[
k[Y]\to k[X].
\]

\section{Common pitfalls}

\begin{warning}[Do not quotient by arbitrary defining equations without checking]
If
\[
X=V(J),
\]
the classical coordinate ring is defined using
\[
I(X),
\]
not automatically using \(J\).  Different ideals can define the same point set.
Over an algebraically closed field,
\[
I(V(J))=\sqrt J
\]
by the Nullstellensatz.
\end{warning}

\begin{warning}[A presentation is not the object]
The rings
\[
k[x,y]/(y-x^2)
\quad\text{and}\quad
k[t]
\]
are isomorphic.  The coordinate ring is an abstract \(k\)-algebra, not a preferred list of
generators and relations.
\end{warning}

\begin{warning}[Classical coordinate rings are reduced]
If nilpotents appear in a quotient presentation, then that quotient is carrying more
information than the classical algebraic set.  This is exactly the extra information schemes
will preserve.
\end{warning}

\begin{warning}[Do not reverse the arrow incorrectly]
A closed inclusion
\[
Y\subseteq X
\]
produces a surjection
\[
k[X]\twoheadrightarrow k[Y].
\]
The direction reverses.
\end{warning}

\section{Chapter summary}

The coordinate ring of an affine algebraic set
\[
X\subseteq\mathbb A_k^n
\]
is
\[
k[X]
=
k[x_1,\dots,x_n]/I(X).
\]
It is canonically the ring of polynomial functions on \(X\).  The residue classes of the
ambient coordinates generate the ring, and the ideal \(I(X)\) records exactly their
relations.

Coordinate rings are finitely generated and reduced.  A point gives an evaluation
homomorphism
\[
k[X]\to k,
\]
while a closed inclusion
\[
Y\subseteq X
\]
gives a quotient
\[
k[X]\twoheadrightarrow k[Y].
\]

The next chapter extends this correspondence from objects to maps.
