# Errata policy

Report a possible mathematical, typographical, bibliographic, accessibility, or
build issue through the repository issue tracker. Use one issue per issue and
include the release version or tag, volume/chapter/section or page, a concise
description, and a minimal correction or counterexample when available.

Maintainers classify reports as `confirmed`, `not reproducible`, `needs source
verification`, or `deferred`. Confirmed release-affecting corrections are added
to this file, linked from the next changelog entry, and preserved with the
release manifest. A correction does not alter an already archived release;
instead it is issued in a later version with its own tag and checksums.

## Confirmed errata

None recorded for the post-v1.3 development line.
