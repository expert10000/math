# Consolidated TeX and Figures

This folder is an organized copy of the imported TeX and figure assets from:

- `imports/Downloads`
- `imports/MATH-ALLS-2`
- `imports/MATH_ALLS-3`

The original import folders were not modified.

Layout:

- `tex/<source>/...` contains document-level `.tex` files.
- `figures/<source>/...` contains image files and `.tex` files that were already inside figure-style folders such as `figures`, `figure`, `figs`, or `.figs`.
- `INDEX.tsv` maps every copied file from its original import path to its consolidated path.

The `Downloads` content follows the existing filtered import: top-level TeX/images plus figure-folder TeX/images, excluding quantum-theory material and PDFs.
