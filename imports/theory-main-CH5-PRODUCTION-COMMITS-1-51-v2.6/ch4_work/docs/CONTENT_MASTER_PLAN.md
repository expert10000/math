# Content Master Plan

## Purpose

Track the scientific and educational assets of the textbook, not only its chapters.

## Asset identifiers

- `DEF-xxxx` — definitions.
- `THM-xxxx` — theorems.
- `LEM-xxxx` — lemmas.
- `PRF-xxxx` — proofs.
- `DRV-xxxx` — derivations.
- `FIG-xxxx` — figures.
- `EXM-xxxx` — worked examples.
- `EXR-xxxx` — exercises.
- `TAB-xxxx` — tables.
- `HIS-xxxx` — historical notes.
- `CMP-xxxx` — computational notes.

## Lifecycle

Planned → Draft → Technical Review → Editorial Review → Integrated → Verified → Frozen

## Chapter 1 initial targets

- 15 definitions.
- 8 theorems or central propositions.
- 20 derivations.
- 20 figures.
- 20 worked examples.
- 60 exercises.
- 6 historical notes.
- 5 computational notes.

## Dependency principle

Definition → theorem → proof → figure → example → exercise → application

The book should function as a connected knowledge system rather than a collection of isolated chapters.
