\section{Physical Meaning of the Derivative}

If

\[
x=x(t),
\]

then

\[
\boxed{
	v=\frac{dx}{dt}
}
\]

is the velocity.

Differentiating once again,

\[
\boxed{
	a=\frac{d^2x}{dt^2},
}
\]

which represents the acceleration.

Thus,

\[
\boxed{
	\text{Derivative}
	=
	\text{Rate of change.}
}
\]
