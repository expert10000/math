\section{Scalars}

A scalar possesses only magnitude.

Examples include

\begin{itemize}
	\item mass,
	\item temperature,
	\item electric potential,
	\item pressure,
	\item energy,
	\item probability density.
\end{itemize}

Scalars do not possess direction.

Examples

\[
T=300\ {\rm K},
\]

\[
m=9.11\times10^{-31}\ {\rm kg}.
\]
