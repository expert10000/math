# PR-BOOK-15.2 - Phase II: Limits

## Scope

This phase continues the mathematical-completeness pass for Chapter 2 by expanding Section 2.2, `Limits`.

## Changes

- Expanded the intuitive meaning of a limit and distinguished limiting values from function values.
- Added the formal epsilon-delta definition.
- Added a complete epsilon-delta proof for a linear function.
- Introduced one-sided limits and the criterion for existence of a two-sided limit.
- Added a jump-discontinuity example.
- Added the principal algebraic limit laws and a worked rational-function example.
- Introduced the squeeze principle and the fundamental trigonometric limit.
- Added continuity at a point and clarified continuity as a physical modeling assumption.
- Connected the limiting process directly to instantaneous velocity.
- Kept the canonical and compatibility source trees synchronized.
