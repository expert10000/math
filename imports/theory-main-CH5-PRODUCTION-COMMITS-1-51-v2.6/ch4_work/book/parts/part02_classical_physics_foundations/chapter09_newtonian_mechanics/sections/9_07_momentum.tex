\section{Momentum}

Momentum is defined by

\[
\boxed{
	\mathbf p
	=
	m\mathbf v.
}
\]

Using momentum,

Newton's second law becomes

\[
\boxed{
	\mathbf F
	=
	\frac{d\mathbf p}{dt}.
}
\]

This form remains valid even when the mass changes.
