\section{Time}

Time is represented by

\[
t.
\]

Unlike spatial coordinates, time is an independent variable.

Instead of writing

\[
\mathbf r,
\]

we now write

\[
\boxed{
	\mathbf r(t).
}
\]

This notation means

\begin{quote}
	``The position depends on time.''
\end{quote}
