\section{Functions}

A function assigns exactly one output to every input.

Examples include

\[
x(t),
\]

\[
y(t),
\]

and

\[
z(t).
\]

Together they define the complete position vector

\[
\boxed{
	\mathbf r(t)
	=
	x(t)\hat{\mathbf x}
	+
	y(t)\hat{\mathbf y}
	+
	z(t)\hat{\mathbf z}.
}
\]

Every moving particle therefore traces a curve through space.
