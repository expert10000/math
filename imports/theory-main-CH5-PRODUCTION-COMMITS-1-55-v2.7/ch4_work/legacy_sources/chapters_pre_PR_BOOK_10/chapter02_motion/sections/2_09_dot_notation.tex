\section{Dot Notation}

In analytical mechanics it is common to use Newton's dot notation.

Instead of writing

\[
\frac{dx}{dt},
\]

we write

\[
\boxed{
	\dot x.
}
\]

Similarly,

\[
\boxed{
	\ddot x
	=
	\frac{d^2x}{dt^2}.
}
\]

For vectors,

\[
\boxed{
	\dot{\mathbf r}
	=
	\mathbf v,
}
\]

and

\[
\boxed{
	\ddot{\mathbf r}
	=
	\mathbf a.
}
\]

This notation will be used extensively in the Lagrangian and Hamiltonian
formulations developed later in this book.
