\section{Total Derivative}

Suppose

\[
f=f(x(t),y(t)).
\]

Now every variable depends upon time.

The total derivative becomes

\[
\boxed{
	\frac{df}{dt}
	=
	\frac{\partial f}{\partial x}
	\frac{dx}{dt}
	+
	\frac{\partial f}{\partial y}
	\frac{dy}{dt}.
}
\]

This is the multivariable chain rule.
