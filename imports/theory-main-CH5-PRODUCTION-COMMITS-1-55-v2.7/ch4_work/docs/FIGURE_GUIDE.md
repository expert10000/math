# Figure Guide

## Purpose

Figures should clarify geometry, dynamics, mathematical structure, or physical interpretation. They are part of the explanation, not decoration.

## Preferred formats

1. TikZ/PGFPlots for mathematical and physical diagrams.
2. SVG for externally prepared vector artwork.
3. PDF for compiled vector figures.
4. Raster images only when the source is inherently photographic.

## Figure classes

- Conceptual diagrams.
- Coordinate and geometry diagrams.
- Function and field plots.
- Process and dependency diagrams.
- Experimental apparatus.
- Summary charts.

## Standards

- Use repository colors and TikZ styles.
- Keep text large enough for print.
- Maintain grayscale readability.
- Use consistent arrowheads, line widths, axes, and label placement.
- Avoid crowded diagrams.
- Include units on plotted axes.
- Ensure captions explain the scientific point.

## Naming

Use descriptive lowercase filenames, for example:

- `cartesian_coordinates.tex`
- `vector_projection.tex`
- `landau_levels_edge_states.tex`

## Checklist

- [ ] Scientifically correct.
- [ ] Referenced in the text.
- [ ] Caption explains the point.
- [ ] Notation matches the chapter.
- [ ] Compiles independently or through the chapter build.
