
## Approval checklist

- [ ] Objectives match the delivered content.
- [ ] All symbols are defined.
- [ ] Major equations are derived and interpreted.
- [ ] Figures are referenced and captioned.
- [ ] Examples cover more than one difficulty level.
- [ ] Exercises are graded.
- [ ] Summary and forward connection are present.
- [ ] Chapter compiles without unresolved references.
