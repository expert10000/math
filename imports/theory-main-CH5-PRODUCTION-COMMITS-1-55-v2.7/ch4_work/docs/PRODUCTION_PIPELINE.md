# Production Pipeline

## Workflow

Writing → Technical Review → Editorial Review → Figure Integration → Example Integration → Exercise Integration → Compilation → Quality Assurance → Publication Ready

## Writing deliverables

- Chapter source.
- Equations and derivations.
- References.
- Learning objectives.
- Summary and forward connection.

## Technical review

Check mathematical correctness, physical correctness, assumptions, notation, and units.

## Editorial review

Check readability, transitions, terminology, pacing, and pedagogy.

## Integration

Add figures, worked examples, exercises, bibliography entries, glossary terms, and symbol-index entries.

## Compilation and QA

- No LaTeX errors.
- No unresolved references.
- Bibliography completes.
- Figures and tables fit correctly.
- Hyperlinks and page layout are verified.

## Publication-ready criteria

A chapter is publication ready only after technical review, editorial review, complete visual and exercise coverage, and a clean reproducible build.
