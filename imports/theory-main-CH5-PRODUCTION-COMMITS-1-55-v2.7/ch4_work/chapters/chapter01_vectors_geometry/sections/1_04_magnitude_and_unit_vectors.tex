\section{Magnitude and Unit Vectors}
\label{sec:magnitude-unit}

\subsection{Magnitude of a Vector}

Consider

\[
\mathbf A=
A_x\hat x
+
A_y\hat y
+
A_z\hat z.
\]

The magnitude is

\[
|\mathbf A|
=
\sqrt{
	A_x^2
	+
	A_y^2
	+
	A_z^2
}.
\]

This is simply the three-dimensional Pythagorean theorem.

\subsection{Unit Vectors}

A unit vector has length one.

Every vector can be written as

\[
\mathbf A
=
|\mathbf A|
\hat{\mathbf A}.
\]

Therefore

\[
\hat{\mathbf A}
=
\frac{\mathbf A}{|\mathbf A|}.
\]
