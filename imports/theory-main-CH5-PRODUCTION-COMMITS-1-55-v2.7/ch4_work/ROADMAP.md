## Completion rule

A figure is complete only when:

1. it compiles independently;
2. it uses shared styles rather than arbitrary local styling;
3. every arrow and axis is physically meaningful;
4. coordinate conventions are explicit;
5. caption and manuscript text agree;
6. labels remain readable at final print size.
