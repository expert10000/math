\section{Stokes' Theorem}
\label{sec:stokes-theorem}
For an oriented surface $S$ with boundary $\partial S$,
\[
\oint_{\partial S}\mathbf F\cdot d\mathbf r
=\iint_S(\nabla\times\mathbf F)\cdot d\mathbf A.
\]
The theorem states that total circulation around a boundary equals the accumulated local curl through any spanning surface.
