\section{Divergence}

For a vector field

\[
\mathbf A
=
(A_x,A_y,A_z),
\]

the divergence is

\[
\boxed{
	\nabla\cdot\mathbf A
	=
	\frac{\partial A_x}{\partial x}
	+
	\frac{\partial A_y}{\partial y}
	+
	\frac{\partial A_z}{\partial z}.
}
\]

The divergence measures the strength of local sources or sinks.
