# Figure review checklist

## Scientific
- [ ] Coordinate axes are defined.
- [ ] Vector directions are correct.
- [ ] Electron charge sign is handled correctly.
- [ ] Units and symbols match the text.
- [ ] Approximation level is stated when needed.

## Visual
- [ ] Shared colours and TikZ styles are used.
- [ ] Labels do not overlap.
- [ ] Text remains readable at page width.
- [ ] Construction lines are visually subordinate.
- [ ] No unnecessary decorative elements are present.

## Editorial
- [ ] Caption explains the purpose of the figure.
- [ ] Figure is referenced in the surrounding text.
- [ ] Label follows naming conventions.
- [ ] Figure compiles independently.
- [ ] Accessibility description can be written clearly.
