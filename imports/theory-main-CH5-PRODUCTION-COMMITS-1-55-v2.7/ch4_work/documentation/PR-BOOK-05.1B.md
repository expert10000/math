## Conventions

- Active rotation: vectors rotate while the original basis remains fixed.
- Passive transformation: components change because the basis changes.
- Cross products use a right-handed coordinate system.
- Scalar triple-product sign records orientation.
- Projection distinguishes scalar and vector projection.
- Translation is treated as an affine transformation.
