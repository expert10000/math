    \textbf{How to structure for \texttt{report}:}
    \begin{itemize}
      \item Use \verb|\chapter{...}| for big blocks (major topics).
      \item Use \verb|\section{...}| and \verb|\subsection{...}| inside chapters.
      \item Avoid starred forms (\verb|\section*| etc.) if you want entries in the Table of Contents.
      \item Compile \textbf{twice} so the Table of Contents is filled.
    \end{itemize}

    \textbf{Quick conversion tip (TeXstudio Find/Replace):}
    \begin{itemize}
      \item Replace \verb|\section*{| with \verb|\section{|
      \item Replace \verb|\subsection*{| with \verb|\subsection{|
      \item For large top-level blocks, replace the first \verb|\section{| with \verb|\chapter{|
    \end{itemize}

    If you insist on unnumbered headings that still appear in the ToC, use the helpers:
    \verb|\chaptertoc|, \verb|\sectiontoc|, \verb|\subsectiontoc|.
